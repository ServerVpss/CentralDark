# Gerenciador de Processos PM2

## Tipo
react-spa

## Descrição
Interface web para gerenciar os 24 processos PM2: start/stop/restart, ver logs, monitorar CPU/memória por processo.

## Requisitos
- Lista completa dos 24 processos
- Status 🟢/🔴 com cor
- Ações: start, stop, restart (via API)
- Gráfico de CPU por processo
- Gráfico de memória por processo
- Busca por nome
- Ordenação: críticos primeiro
- Confirmação antes de ações destrutivas
