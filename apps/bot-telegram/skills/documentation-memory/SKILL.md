# Skill: Documentation & Memory

### Quando usar
Ao final de toda e qualquer alteração no projeto.

### Objetivo
Manter a continuidade do desenvolvimento, permitindo que qualquer IA ou humano retome o trabalho sem perda de contexto.

### Passos obrigatórios
1. Atualizar o `docs/CHANGELOG_TECNICO.md` com as mudanças do dia.
2. Manter o `docs/STATUS_ATUAL_DO_PROJETO.md` atualizado com o ponto exato de parada.
3. Registrar: resumo leigo, explicação técnica, arquivos afetados, riscos e testes realizados.

### O que é proibido
- Encerrar uma sessão de trabalho sem atualizar os arquivos de memória.

### Como validar
Verificar se os arquivos na pasta `/docs/` refletem as mudanças no código.

### Critério para considerar concluído
A documentação está 100% sincronizada com a versão atual do sistema.
