# Árvore Semântica da Casa

> Esta nota é a projeção humana/Obsidian da lei canônica. Se houver divergência, governa `docs/CONSCIENCIA/01-IDENTIDADE-E-REGRAS/LEI-ARVORE-SEMANTICA-DA-CASA.md`.

## Forma da Casa

```text
BRAIN
├─ 00-MAPA-SISTEMA
├─ 01-CONCEITOS
├─ 02-ENTRADA
├─ 03-DOCUMENTACAO
├─ 04-DECISOES
├─ 05-DEVEDORES-CONTATOS
├─ 06-REUNIOES-NOTAS
├─ 07-APRENDIZADOS-MEMORIAS
├─ 08-ARTEFATOS-VISUAIS
└─ 09-RESERVA-CANONICA
```

Cada nível repete a mesma gramática:

```text
00 = índice/mapa/meta quando necessário
01..09 = categorias materiais
máximo = 10 filhos diretos
crescimento adicional = aprofundar dentro do owner semântico correto
```

## O que cada camada significa

```text
PASTA       = endereço físico
NÚMERO      = endereço estável
NOME        = significado humano
PROPRIEDADE = identidade/classificação da nota
TAG         = filtro/faceta
WIKILINK    = relação explícita
BACKLINK    = relação recebida
MOC         = mapa do bairro
GRAFO       = projeção das relações
VETOR       = proximidade por significado
```

## Gramática visual sugerida

| Área | Função | Família visual |
|---|---|---|
| `00-MAPA-SISTEMA` | navegação/mapa | prata/neutro |
| `01-CONCEITOS` | conceitos | violeta |
| `02-ENTRADA` | matéria nova | âmbar |
| `03-DOCUMENTACAO` | documentação/biblioteca | azul/cyan |
| `04-DECISOES` | decisões | laranja |
| `05-DEVEDORES-CONTATOS` | domínio humano específico | vermelho-terra |
| `06-REUNIOES-NOTAS` | encontros/notas | magenta |
| `07-APRENDIZADOS-MEMORIAS` | aprendizado/memória | verde |
| `08-ARTEFATOS-VISUAIS` | SVG/Mermaid/mapas/imagens | turquesa |
| `09-RESERVA-CANONICA` | espaço reservado por necessidade provada | cinza |

As cores são navegação, nunca verdade. Status `GREEN/YELLOW/RED` continua reservado para estado/prova temporal.

## Regras de linkagem

```text
LINKAR SE:
- mesma decisão afeta dois conceitos
- nota deriva de fonte conhecida
- artefato visual deriva de nota/fonte
- aprendizado fecha erro/causa conhecida
- MOC precisa ligar bairro real

NÃO LINKAR SE:
- apenas parece relacionado
- é para deixar o grafo bonito
- semântica é inferida sem evidência suficiente
```

## Artefatos vetoriais

Quando houver capacidade existente no Router para SVG/Mermaid/visualização:

```text
NOTA/FONTE
→ capability router existente
→ SVG/MERMAID/ARTEFATO
→ 08-ARTEFATOS-VISUAIS/<owner correto>
→ backlink para fonte
```

Nenhum visual vira owner só por ser bonito.

## Ritual de reconciliação

```text
ACHOU FORA DO LUGAR
→ identificar
→ comparar conteúdo/hash quando material
→ localizar owner
→ fundir se complementar
→ mover se único
→ não duplicar
→ validar links/consumidores
→ remover origem reconciliada
→ registrar
```

A parceria da Casa é operacional: o CHEFE define intenção e padrão; Hermes mantém ordem, continuidade e execução; SOL coordena/reconcilia; realidade julga.
