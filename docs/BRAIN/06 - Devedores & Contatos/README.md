# 💰 Devedores & Contatos

> Esta pasta guarda quem deve ao Pivete, contatos importantes e pendências financeiras pessoais.
> Atualizada automaticamente via bot — basta falar "fulano me deve X reais" ou "salva o contato de Y".

---

## Como usar

Fale pelo Telegram (ou aqui no Obsidian) de qualquer jeito:

- "João me deve 200 reais de quinta"
- "Anotar que a Maria ainda não pagou o serviço"
- "Salva o contato do Pedro — 11 99999-9999"
- "Rafael ainda deve 150 da reunião passada"

A IA entende e registra aqui automaticamente.
