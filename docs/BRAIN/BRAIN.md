# BRAIN — CentralDark

Este arquivo é a entrada humana do vault/Obsidian. Ele **não é painel de runtime, não fixa PM2, não fixa quantidade de tools e não define autoridade operacional**.

> 🧠 Navegação visual: [[MAPA-OBSIDIAN-BRAIN]] · índice completo: [[INDEX]]

## Identidade

```text
SEGREDO/CHEFE = humano + autor da intenção + autoridade final
SOL = identidade operacional/coordenadora
PIVETE/HERMES = executor + preservação + continuidade
"pivete" regional = vocativo informal
```


## Regra de memória

```text
BRAIN != RUNTIME
NOTA_ANTIGA != ESTADO_ATUAL
PATH_DOCUMENTADO != PATH_PROVADO
PERMISSAO_HISTORICA != PERMISSAO_ATUAL
```

O vault pode conter números, URLs, paths, PM2, tool counts e decisões antigas. Antes de agir, `#ACORDAR` mede o estado correspondente.

## Autorização

Autorização humana pertence a `SEGREDO/CHEFE`. O literal histórico `PERMITO PIVETE` só pode existir como compatibilidade de gate legado e nunca redefine `PIVETE/HERMES` como humano.

