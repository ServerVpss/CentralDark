# 🎮 Pontos & Níveis do CHEFE

> Gamificação simbólica da trajetória registrada. Serve para narrativa, milestones e memória contextual. **Não é score de autoridade, competência ou verdade operacional.**

## Regra de leitura

```text
XP = METADADO_NARRATIVO
LEVEL = MARCO_DE_HISTÓRIA
XP != PROVA
LEVEL != AUTORIDADE
REALIDADE = JUIZ
```

## Marcos

| Nível | Título | Lição preservada |
|---:|---|---|
| 1 | Sobrevivente do Caos | continuar mesmo sem mapa pronto |
| 10 | Caçador de Padrões | perguntar por que o erro volta |
| 20 | Construtor de Cânone | separar source/runtime, history/current e unknown/pass |
| 30 | Orquestrador | várias ferramentas como capacidades de um organismo |
| 40 | Arquiteto de Continuidade | experiência vira memória e candidato de conselho |
| 45 | Guardião do Delta Contínuo | checkpoint não encerra missão; múltiplos agentes preservam o mesmo fio |
| 50 | A Casa que se Aconselha | próximo marco; conselho com proveniência e contraprova |

## XP simbólico da fase atual

```text
XP +50   sobreviver ao erro sem esconder o erro
XP +100  separar merge de deploy
XP +200  separar source de runtime
XP +500  recusar UNKNOWN como PASS
XP +800  reconhecer padrão recorrente
XP +1200 preservar missão entre agentes e checkpoints
XP +1600 transformar experiência em memória reutilizável
```

Não somar estes números para decisões operacionais. Eles existem para contar a história e destacar o tipo de aprendizado adquirido.

## Como um nível sobe

```text
EVENTO REAL
→ HISTÓRICO FACTUAL
→ LIÇÃO EXPLÍCITA
→ DELTA REUTILIZÁVEL
→ DREAM REVIEW / CONTRAPROVA
→ NOVO MARCO NARRATIVO
```

Sem lição reutilizável, não existe necessidade de criar novo nível.
