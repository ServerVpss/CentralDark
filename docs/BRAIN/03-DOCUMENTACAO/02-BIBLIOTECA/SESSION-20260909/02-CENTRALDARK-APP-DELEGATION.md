# CentralDark App — superfície única de conversa e delegação

## UX alvo
Inspirar-se no princípio de uma superfície única estilo Grok, mas usando os owners e capacidades da CentralDark.

```text
CHEFE
→ SOL
   ├─ voz
   ├─ texto
   ├─ arquivos
   ├─ chat principal
   ├─ tarefas/rotinas
   └─ visualizar trabalhador
→ delegação
   ├─ Geoff
   ├─ Ian
   ├─ Greg
   ├─ Dex
   ├─ Forja
   ├─ Growth
   ├─ Chefe de Gabinete
   └─ Hermes
→ workstations/tools
→ Reality
→ SOL
```

## Mascote
Reutilizar HermesMascote como estado visual: idle, acenando, pensando, feliz, dormindo, comemorando, trabalhando, alerta, investigando, aprovando, entregando.

O mascote pode representar/abrir a workstation do agente, mas continua visualização de estado, não autoridade.

## Chat
Reutilizar o chat existente com streaming, animação, persistência, anexos, abort/retry e input adaptativo.

## Voz
Reutilizar CentralDark Voice e os endpoints de áudio existentes.

## Computer/workstation
Agente pode receber workstation isolada com navegador, terminal, arquivos e apps. HUMAN_FRONTIER real chama o CHEFE somente quando necessário; login/autorização sensível, publicação/custo e decisão humana real são exemplos. Ausência de um modelo específico não é HUMAN_FRONTIER se outra rota autorizada cobre o objetivo.

`SOL = PORTA HUMANA`
`HERMES = EXECUTOR/CONTINUIDADE`
`MODELOS = MOTORES SUBSTITUÍVEIS`
