# Plugins Obsidian Recomendados para o CentralDark

> Instale nessa ordem. Cada um tem motivo claro pra estar aqui.

---

## Prioridade de instalação

| # | Plugin | Por que instalar |
|---|--------|-----------------|
| 1 | **Dataview** | Cria listas e tabelas dinâmicas automáticas — essencial pra MOCs e pendências |
| 2 | **Templater** | Templates inteligentes com data, estrutura padrão e seção de conexões automática |
| 3 | **Breadcrumbs** | Relações hierárquicas entre notas ("é parte de", "explica") — melhora muito o Graph View |
| 4 | **Juggl** | Visualização de grafo muito mais bonita e configurável que o nativo |
| 5 | **Tasks** | Gerencia pendências com datas e prioridades direto no Obsidian |
| 6 | **Excalidraw** | Diagramas e esquemas — ótimo pra arquitetura do CentralDark |

---

## Todos os recomendados por categoria

### Essenciais

| Plugin | Utilidade |
|--------|-----------|
| **Dataview** | Consultas dinâmicas em notas — substitui tabelas manuais |
| **Templater** | Templates com data automática, estrutura padrão, seção de conexões |
| **Breadcrumbs** | Relações semânticas explícitas — muito melhor que link comum |
| **Obsidian Git** | Controle de versão (já instalado ✅) |
| **Folder Notes** | Transforma pastas em notas clicáveis — navegação mais limpa |

### Visualização e Graph

| Plugin | Utilidade |
|--------|-----------|
| **Juggl** | Melhor visualização de grafo disponível (já instalado ✅) |
| **Graph Analysis** | Métricas do grafo — quais notas estão isoladas, mais conectadas |
| **ExcaliBrain** | Combina Excalidraw com grafo — mapas mentais do sistema |

### Linkagem Semântica

| Plugin | Utilidade |
|--------|-----------|
| **Breadcrumbs** | Relações tipadas entre notas |
| **Smart Connections** | IA sugere links entre notas (verificar política de privacidade) |
| **Note Linker** | Sugere links automaticamente ao escrever |
| **Tag Wrangler** | Gerencia tags de forma mais poderosa |

### Produtividade

| Plugin | Utilidade |
|--------|-----------|
| **Tasks** | Tarefas com datas e filtros — bom pras pendências do CentralDark |
| **Kanban** | Quadro visual de tarefas |
| **Calendar + Periodic Notes** | Notas diárias/semanais organizadas |

### Visual

| Plugin | Utilidade |
|--------|-----------|
| **Style Settings** | Customiza temas em detalhes (quase obrigatório com tema bonito) |
| **Excalidraw** | Diagramas de arquitetura do sistema |
