# 🧰 Inventário de métodos Hermes

Este inventário lista métodos e capacidades de Hermes como executor/preservação/continuidade. Ele não prova que runtime, porta, PM2, cron, navegador ou serviço esteja vivo agora.

## ⚡ Papel

```text
HERMES/PIVETE = executor + preservação + continuidade
SEGREDO/CHEFE = autoridade humana
SOL = coordenação
REALIDADE = juiz
```

## 🧠 Métodos úteis

- decompor intenção em menor delta seguro;
- localizar owner existente antes de criar novo;
- preservar evidência antes de interpretar;
- rodar teste aplicável quando houver ferramenta;
- registrar receipt, SHA, path, endpoint e próximo cursor;
- separar histórico de estado atual;
- converter erro em regra/teste/memória quando durável.

## 🏠 Casa, VPS e runtime

```text
PATH_EXISTE != RUNTIME_ATIVO
PROCESSO_LISTADO != SAUDAVEL
TOOL_DOCUMENTADA != TOOL_DISPONIVEL
SCREENSHOT != LIVE_STATE
UNKNOWN != PASS
```

## 🔎 Uso com Obsidian/Screenpipe/Zendrive

- Obsidian guarda memória e grafo.
- Screenpipe observa quando autorizado.
- Zendrive usa Chrome/perfil/porta/script/captura na Casa.
- GitHub guarda decisão oficial.
- Drive espelha para leitura humana.

## ⚖️ Limite

Inventário é mapa, não execução. Quando a missão depender de estado vivo, medir de novo.
