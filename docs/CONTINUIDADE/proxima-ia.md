# 🔄 PRÓXIMA IA — Entrada viva de continuidade CentralDark

Este arquivo é um **entrypoint estável**, não um snapshot de runtime congelado.

O conteúdo antigo de 2026-06-28 continua preservado no histórico Git, mas não governa o estado atual.

## 👑🪬 Entrada obrigatória

```text
👑🪬 !CENTRALDARK
→ 🔗 !># INTERLIGADOS
→ ⭕ !AURÉOLA CANÔNICA
→ 🏛️ GITHUB MAIN VIVA
→ 🫀 SOUL ATUAL
→ 🔌 MCP / HUB / CONNECTORS disponíveis
→ 🏠 RUNTIME / CASA / VPS / WEB quando aplicável
→ ⚖️ REALIDADE
```

## 🧿 O que a próxima IA faz

1. carregar `LEIA-ME-IA.md` e `AGENTS.md`;
2. ler o owner atual do padrão de resposta e o padrão do grafo vivo;
3. buscar a `main` viva antes de repetir estado antigo;
4. recuperar somente contexto relevante para a missão atual;
5. medir runtime apenas quando o claim depender dele;
6. separar claramente fato atual, histórico e `UNKNOWN`;
7. reutilizar owner existente antes de criar arquivo, agente ou fluxo novo;
8. registrar delta material no owner correto, sem duplicar handoff.

## 🕰️ Regra anti-snapshot falso

```text
HANDOFF_PATH=ESTAVEL
RUNTIME_STATE=REMEDIDO
HISTORY != CURRENT_STATE
OLD_SHA != CURRENT_HEAD
OLD_PROVIDER_STATE != CURRENT_PROVIDER_STATE
UNKNOWN != PASS
```

Este arquivo não deve acumular blocos diários de estado. Eventos históricos, receipts e relatórios ficam nos destinos próprios; aqui permanece apenas o contrato de entrada para a próxima IA.
