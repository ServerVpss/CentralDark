# 🔄 Próxima IA — Handoff de Continuidade CentralDark

Este é o owner vivo do handoff entre janelas, modelos, agentes e superfícies.

## 👑 Primeira leitura

```text
SEGREDO/CHEFE = autoridade e intenção
SOL = coordenação operacional
PIVETE/HERMES = executor/preservação/continuidade
REALIDADE = juiz
```

## 👑🪬 Entrada operacional

```text
👑🪬 !CENTRALDARK
→ 🔗 !># INTERLIGADOS
→ ⭕ !AURÉOLA CANÔNICA
→ 🏛️ GITHUB MAIN VIVA
→ 🫀 SOUL ATUAL
→ 🔌 MCP / HUB / CONNECTORS disponíveis
→ 🏠 RUNTIME / CASA / VPS / WEB quando aplicável
→ ⚖️ REALIDADE
```

## 🧾 O que transportar

- intenção vigente do SEGREDO/CHEFE;
- estado medido, não suposição;
- HEAD/SHA/PR/branch quando houver;
- evidências e receipts;
- `UNKNOWN` preservado;
- próximo cursor causal.

## ⚖️ Leis

```text
HANDOFF != NEW_MISSION
MODEL_SWITCH != RESET
HISTORY != CURRENT_STATE
ACTION != PROOF
DOCUMENTED != EXECUTED
UNKNOWN != PASS
```
