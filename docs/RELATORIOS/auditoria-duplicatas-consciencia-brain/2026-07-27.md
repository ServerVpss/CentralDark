## 4. Causa raiz (prova de criação — canal 4: diff contra commit pai)

```
commit 9b8eeec4eeb577dde2c698919f2c662cb5d88813
autor: SegredoiDev (bot) · 2026-07-02T16:29:03Z
msg:   "fix(memory-executor): auto-corrige 129 gap(s) de memória" (adicionar frontmatter)
```

`github_list_commits(path=docs/CONSCIENCIA/CONSCIENCIA/CONSCIENCIA.md, perPage=100)` retorna
**exatamente 1 commit** — o de cima. `github_list_commits(path=docs/CONSCIENCIA/BRAIN/BRAIN.md,
perPage=3)` retorna o **mesmo commit** como o mais recente.

Prova direta: `github_read` de `docs/CONSCIENCIA/CONSCIENCIA/README.md` e de
`docs/CONSCIENCIA/BRAIN/BRAIN.md` no commit PAI (`c454c960749b66dc59bf060d767706da0d12780a`)
retorna **404 nos dois** — os caminhos não existiam antes desse commit.

**Conclusão de causa raiz:** o mesmo commit de bot que deveria só adicionar frontmatter a
arquivos existentes criou, de quebra, duas cópias aninhadas inteiras de subarvores já
existentes — mesmo padrão do bug achado nesta sessão em
`scripts/github-bot-controller.mjs` (prefixo de caminho duplicado por resolução relativa
incorreta). Nenhuma das duas árvores foi tocada organicamente desde então.

## 5. Limitação de ferramenta encontrada (registrar para não repetir)

`github_commit` (MCP CentralDark) **não suporta delecao**. Testado nesta auditoria: chamado
com `{path, content:"", delete:true}` em `docs/CONSCIENCIA/CONSCIENCIA/README.md` — o campo
`delete` foi ignorado silenciosamente; o resultado foi um arquivo de 0 bytes (blob vazio
`e69de29`), não a remoção do path. Restaurado o conteúdo original no mesmo commit seguinte
(prova: commits `29fe55f` → `caf26ec` na branch desta auditoria).

`device_bash` não tem rede (não faz `git push`); `Bash` (container cloud) não tem credencial
git válida para este repositório (`GITHUB_TOKEN`/`GH_TOKEN` do ambiente não autenticam no GitHub).
Nenhuma ferramenta disponível nesta sessão consegue apagar arquivos do repositório.

**Consequência:** a eliminação real precisa rodar num ambiente com `git` + push real —
a VPS (que já tem esse acesso e já rodou `scripts/run-once/reorganizar-consciencia.sh` do
mesmo jeito) ou o Pivete localmente. O script pronto está em
`scripts/run-once/eliminar-duplicatas-consciencia-brain.sh` nesta branch — um comando único,
idempotente (`test -d` antes de mexer), com o commit message já com a prova embutida.
