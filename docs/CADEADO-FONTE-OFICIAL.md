# 🔒 CADEADÃO — FONTE OFICIAL DOS DOCUMENTOS

A fonte oficial dos documentos é esta pasta:

`/root/CentralDark/docs`

A pasta `/root/docs` não deve mais ser usada como fonte separada. Ela deve apontar para a pasta oficial, para evitar duas verdades e relatório sumido.

Regras:
- não criar nova documentação fora de `/root/CentralDark/docs`;
- não salvar relatório novo em `/root/docs` como pasta independente;
- se aparecer conflito legado, revisar `_LEGADO_ROOT_DOCS_CONFLITOS/` antes de apagar qualquer coisa;
- não envolver Lovable/Supabase nessa operação de docs da VPS sem ordem explícita.
