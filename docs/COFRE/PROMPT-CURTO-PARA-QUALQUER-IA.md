# Prompt curto universal para qualquer IA

Copie e envie este texto ao Grok, Claude, Gemini, ChatGPT, Copilot ou outro agente:

```text
Antes de tocar no CentralDark:

1. Abra a branch autorizada.
2. Leia AGENTS.md na raiz.
3. Leia docs/COFRE/README.md.
4. Execute o BOOT indicado em docs/GOVERNANCA/BOOT-IA.md.
5. Confirme branch, SHA, ambiente, escopo, riscos, testes e rollback.
6. Não altere nada antes de concluir o BOOT.
7. Nunca edite diretamente na main.
8. DEV só implanta em DEV; AUDITORIA só implanta em AUDIT/STAGING.
9. Nenhum deploy sem commit e push.
10. Responda ao Pivete no formato FORMA → LEIGO → DESCRIÇÃO TÉCNICA.
```

A fonte da verdade é o GitHub, não a memória da conversa.
