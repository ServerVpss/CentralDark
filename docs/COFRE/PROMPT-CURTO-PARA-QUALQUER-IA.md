# Prompt curto universal para qualquer IA

Copie e envie este texto ao Grok, Claude, Gemini, ChatGPT, Codex, Copilot ou outro agente:

```text
Antes de tocar no CentralDark:

1. Abra ou inspecione a branch pivete/dev.
2. Leia 00-COMECE-AQUI-IA.md.
3. Leia integralmente CLAUDE.md como Constituição universal de todas as IAs.
4. Leia AGENTS.md e a hierarquia oficial.
5. Leia docs/COFRE/README.md.
6. Execute o BOOT indicado em docs/GOVERNANCA/BOOT-IA.md.
7. Confirme workspace, ref inspecionada, SHA, ambiente, escopo, riscos, entradas externas, testes, prova e rollback.
8. Não altere nada antes de concluir o BOOT.
9. Nunca edite diretamente na main.
10. DEV só implanta em DEV; AUDITORIA só implanta em AUDIT/STAGING.
11. Nenhum deploy sem commit e push.
12. Responda ao Pivete no formato FORMA → LEIGO → DESCRIÇÃO TÉCNICA.

Arquivos específicos de ferramentas são apenas pontes. Nenhum deles pode contradizer CLAUDE.md.
```

A fonte da verdade é o GitHub, não a memória da conversa.
