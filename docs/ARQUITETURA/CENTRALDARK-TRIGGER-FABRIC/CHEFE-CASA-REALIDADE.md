# CHEFE · CASA · REALIDADE

## Destino

Cristalizar a separação entre autoridade humana, centro operacional e prova material sem criar novo cérebro, router, Judge, memória ou owner.

```text
SEGREDO/CHEFE
→ define intenção
→ define destino
→ decide aceitação humana final

CASA CENTRALDARK
→ mede
→ recupera contexto autorizado
→ orquestra capacidades e fontes
→ executa quando autorizada
→ produz efeito observável
→ registra receipt

REALIDADE MATERIAL
→ limita o que pode ser chamado de fato técnico
→ invalida falso-verde
→ responde à execução com evidência observável

GPT / modelos / agentes externos
→ fontes, motores, auditores ou contraprovas substituíveis
→ não são control plane obrigatório
→ não viram autoridade por repetição, eloquência ou quantidade de janelas
```

## Lei curta

```text
CHEFE_DEFINE_DESTINO=true
CHEFE_FINAL_ACCEPTANCE_AUTHORITY=true
CASA_IS_OPERATIONAL_CENTER=true
MODEL_IS_REPLACEABLE=true
EXTERNAL_CHAT_IS_OPTIONAL_SOURCE=true
EXTERNAL_CHAT_IS_REQUIRED_CONTROL_PLANE=false
REALITY_CONSTRAINS_TECHNICAL_PASS=true
CLAIM_WITHOUT_EVIDENCE_IS_NOT_PASS=true
WINDOW_COUNT_IS_NOT_VOTE=true
REPETITION_IS_NOT_PROOF=true
```

`REALITY=JUDGE` significa que nenhuma IA, documento, screenshot, log isolado ou declaração pode fabricar `PASS` técnico sem elo observável suficiente. Isso não transforma SOL, Hermes, GitHub ou qualquer modelo em autoridade humana sobre o CHEFE.


## Casa como centro, superfícies como braços

O objetivo operacional é reduzir transporte manual de contexto pelo humano.

```text
CHEFE
→ UMA JANELA DA CASA
→ capability router
→ arquivos locais autorizados
→ memória/Obsidian quando aplicável
→ Screenpipe/Recorder quando aplicável e autorizado
→ GitHub
→ VPS/runtime/logs
→ Web/docs quando necessários
→ fanout read-only
→ rendezvous/dedupe
→ ação serializada por Writer único
→ prova + contraprova
→ receipt
```

Muitas capacidades não exigem muitas janelas humanas.

```text
MANY_CAPABILITIES=true
MANY_HUMAN_WINDOWS_REQUIRED=false
ONE_CORE_MANY_ARMS=true
PARALLEL_PERCEPTION=true
SERIALIZED_MUTATION=true
```

## Uso correto de chats/modelos externos

ChatGPT, Codex, Claude, Grok e outros modelos podem acrescentar pesquisa, hipótese, auditoria, contraprova ou capacidade especializada. Eles não precisam participar de cada passo da missão.

```text
CASA_CAN_WORK_WITHOUT_EXTERNAL_CHAT=true
EXTERNAL_CHAT_CAN_ADD_DELTA=true
HUMAN_COPY_PASTE_AS_PERMANENT_BUS=false
```

Quando o CHEFE copia manualmente uma conclusão de uma superfície para outra, o canal causal observado é o próprio transporte humano. Isso pode ser útil como experimento, mas não deve ser confundido com sincronização automática entre chats.

## PAPAGAIO OFF

```text
NO_NEW_DELTA → SILENCE
OPINION_WITHOUT_PROOF → CANDIDATE_ONLY
SENSOR_WITH_TIMESTAMP_PROVENANCE → EVIDENCE_CANDIDATE
NOISE_REPETITION_ECHO → DROP_OR_DEDUPE
```

A Casa pode usar sensores e fontes estruturadas, mas sensor não vira Judge, owner ou Writer por emitir informação.

## Fixed point

A missão global não fecha porque uma fila ficou vazia, um PR mergeou, uma tela ficou verde ou um modelo disse `DONE`.

```text
LOCAL_FIXED_POINT != GLOBAL_MISSION_CLOSED
MERGED != DEPLOYED
DEPLOYED != HEALTHY
DOCUMENTED != EXECUTED
ACTION != PROOF
UNKNOWN != PASS
```

Fechamento global exige objetivo material encerrado, estado aplicável medido, contraprova sobrevivida e aceitação final do CHEFE.

```text
PROJECT_GLOBAL_FIXED_POINT =
  GLOBAL_OBJECTIVE_CLOSED
  + APPLICABLE_MATERIAL_UNKNOWN_ZERO
  + T1_STABLE
  + COUNTERPROOF_SURVIVES
  + CHEFE_FINAL_ACCEPTANCE
```

## Resultado operacional

```text
CHEFE → intenção e decisão
CASA → centro operacional
SOL → coordena/reconcilia/contraprova
HERMES → executa/preserva
MODELOS → braços substituíveis
REALIDADE MATERIAL → impede falso PASS
RECEIPT → preserva continuidade
```

A regra soberana de prova permanece simples:

> Sem prova, não passa.
