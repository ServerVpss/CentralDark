# CentralDark - Multi-Model Delta Crystallizer

## Principio

Nao existe chat vencedor por beleza, tamanho ou modelo. Varios agentes podem enxergar partes diferentes do mesmo fenomeno. A CentralDark extrai a intersecao, separa delta util, mede contradicoes e so cristaliza o que aguenta prova.

```text
MODELO != VERDADE
RESPOSTA != VERDADE
CONSENSO != PROVA FINAL
A intersecao + delta sobrevivente + medicao = verdade atual cristalizada
```

## Lentes permitidas

```yaml
lenses:
  CHAT_A: intencao -> medicao -> delta -> prova
  CHAT_B: caos -> garimpo -> owner -> gate -> receipt
  GPT_5_5: comportamento sistemico -> risco -> autoridade/executor/prova -> self-healing
```

Nenhuma lente substitui o contrato. Cada lente fornece angulo, proveniencia e possivel delta.

## Regra de promocao

```text

MUTACAO_TEM_QUE_SER_SERIALIZADA
```

Ou seja: dez janelas podem perceber, mas a escrita canonica precisa passar por owner, gate, receipt e cursor.

## Frase canonica

Quando varios agentes respondem diferente, a CentralDark nao escolhe o mais bonito. Ela extrai o que se repete, separa o delta util, mede contradicoes e so cristaliza o que vira prova.
