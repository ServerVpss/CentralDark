## Counterproof law

```text
PROVEN_CLAIM
→ SAME_TARGET
→ SAME_LAYER
→ TOP_DOWN
→ BOTTOM_UP
→ ROUND_TRIP
→ PROOF_TARGET_MATCH
→ INDEPENDENT_CHECK WHEN MATERIAL
→ OUTPUT_GUARD
→ SURVIVES?
   YES → keep PROVEN
   NO  → FAIL
   UNMEASURED → UNKNOWN
```
