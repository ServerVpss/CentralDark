## Counterproof law

```text
PROVEN_CLAIM
→ SAME_TARGET
→ SAME_LAYER
→ TOP_DOWN
→ BOTTOM_UP
→ ROUND_TRIP
→ PROOF_TARGET_MATCH
→ INDEPENDENT_CHECK WHEN MATERIAL
→ OUTPUT_GUARD
→ SURVIVES?
   YES → keep PROVEN
   NO  → FAIL
   UNMEASURED → UNKNOWN
```

Any claim that depends on current runtime must remeasure runtime. Repository existence alone is insufficient. Any claim that depends on current Git state must remeasure HEAD/PR before final verdict.
