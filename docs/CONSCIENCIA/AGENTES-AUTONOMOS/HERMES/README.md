2. Rodar `ls AULAS/` — pegar as aulas por ordem numérica
3. Rodar `cat ROTAS-FIXAS/*.md` — ter os atalhos na cabeça
4. Rodar `cat APRENDIZADOS/INDICE.md` — ver histórico curto
