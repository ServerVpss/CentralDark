# 🧠 Hermes — Árvore de Conhecimento

Este diretório concentra TUDO sobre o agente Hermes. Nada de espalhar.

## Estrutura

```
HERMES/
├── README.md              ← este arquivo (índice)
├── STATUS.md              ← ficha viva: nível, XP, skills
├── AULAS/                 ← ensinamentos formais (TEMPLATE-AULA.md)
├── APRENDIZADOS/          ← lições curtas do dia (TEMPLATE-APRENDIZADO.md)
├── ROTAS-FIXAS/           ← atalhos de execução
├── DEBATES/               ← consultas ao Hermes real
├── EVOLUCAO/              ← marcos de auto-melhoria
└── SUGESTOES/             ← auto-melhoria pendente de aprovação
```

## Regra de ouro

**Tudo do Hermes vive aqui dentro.** Aprendizados sobre Hermes NÃO vão pro `docs/CONSCIENCIA/APRENDIZADOS.md` geral.

## Loop obrigatório (AULA-011)

```
LER (graph → memória → consciência) → VERIFICAR colisão (Fabler?)
  → AGIR (rota-fixa) → REGISTRAR (aprendizado + XP + rastro)
  → SUGERIR melhoria (SUGESTOES/)
```

## Como consumir (Hermes ou IA nova entrando)

1. Ler `README.md` + `STATUS.md`
2. Ler `AULA-011` (loop mestre — auto-aprendizagem)
3. `ls AULAS/` — aulas por ordem numérica
4. `cat ROTAS-FIXAS/*.md` — atalhos na cabeça
5. `cat APRENDIZADOS/INDICE.md` — histórico curto
6. Só ENTÃO agir
