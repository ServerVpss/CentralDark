# HERMES/SUGESTOES — Caixa de auto-melhoria

Todo bloco fechado termina com a pergunta: **"o que eu faria diferente da próxima?"**
Se tem resposta, vira arquivo aqui.

## Formato
`NNN-slug.md` com o template abaixo:

```md
# SUG-NNN — <título>
**Data:** YYYY-MM-DD
**Nasceu em:** BLOCO/AULA/APR X
**Categoria:** [otimização | novo-processo | ferramenta | atalho | rota-nova]
**Status:** [proposta | aprovada | rejeitada | virou AULA-XXX]

## Observação
O que percebi durante a execução.

## Proposta
O que mudar.

## Custo/benefício
- Ganho:
- Custo:
- Quebra algo? (S/N + o quê)

## Próximo passo (se admin aprovar)
Ação concreta e curta.
```

## Regras
- Admin lê periodicamente. Aprovada → vira AULA nova ou ROTA-FIXA.
- Rejeitada → fica arquivada com motivo (aprendizado negativo também conta).
- Nunca deletar sugestão — histórico de raciocínio é ouro.
