# Handoff oficial para outro GPT / outra sessão

```txt
Me dê um handoff para reiniciar esta sessão em um novo chat sem perder o contexto.

Inclua:
- O que decidimos
- O que construímos
- Próximos passos
- Restrições importantes
- Riscos / pendências

Mantenha curto, claro, acionável e leve.
Se possível, deixe abaixo de 500 tokens.
```

## Regra operacional
- sessão pesada -> gerar handoff
- novo chat -> colar handoff
- continuar com contexto leve
- preservar detalhe longo em artefatos
