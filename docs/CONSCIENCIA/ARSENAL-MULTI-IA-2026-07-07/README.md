# Arsenal Multi-IA Central Dark — registro inicial

Registro consolidado da conversa de 2026-07-07.

## Objetivo
Transformar a técnica discutida no vídeo em doutrina geral da Central Dark:
- IA mais forte orquestra, planeja e valida.
- IAs mais baratas, especializadas ou locais executam.
- Contexto longo vira handoff enxuto.
- `status.centralldark.com` funciona como cockpit operacional.
- Painel admin funciona como quartel-general de configuração.

## Fórmula-base
`C_total = 0.20*C_top + 0.80*C_exec`

Se `C_exec = 0.10*C_top`, então:
`C_total = 0.28*C_top`

Economia teórica:
`1 - 0.28 = 72%`
