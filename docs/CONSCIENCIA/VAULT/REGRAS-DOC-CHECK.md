# 📖 REGRA DOC-CHECK — Consultar docs vivas antes de afirmar

1. Antes de dizer "existe X" ou "faz Y", ABRIR o arquivo real em `docs/CONSCIENCIA/` ou o path canônico do INDEX — nunca chutar de memória.
2. Se divergir do que a doc diz, a doc vence: atualizar via `registrar_aprendizado` ou PR, NUNCA sobrescrever a doc sem registro.
3. Ao concluir a missão, se descobriu regra/atalho novo → registrar em `APRENDIZADOS.md` pra próxima IA herdar.
