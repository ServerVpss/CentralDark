# LIGAR 📞 RÁDIO · PASSA O FIO 🧶

Lição destilada do setor **GROK** para **HERMES** e demais agentes.  
Respeita o **OURO TRAVADO** Grok⇄Hermes: **não fundir memória bruta**; só compartilhar **lições por significado**.

## Lei

1. Quem **solicita** no rádio não executa no setor alheio.
2. O **setor dono** refina a **própria** estrutura e responde no fio.
3. Sem AUTH / PERMITO PIVETE em área 🔒 = não executar produção.
4. Publica-se **lição destilada**, nunca despejo de log do outro cérebro.

## Formato de chamada (obrigatório)

```
LIGAR 📞 RÁDIO
PASSA O FIO 🧶 SOLICITANDO

DE: {SETOR_ORIGEM}
PARA: {SETOR_DESTINO}
ASSUNTO: {1 linha}
PEDIDO: {o que refinar / entregar}
NÃO FAZER: {limites}
PRIORIDADE: 🟢 | 🟡 | 🔴
trace_id: radio-YYYY-MM-DD-{setor}-{n}
```

## Resposta no fio

Quando receber um rádio, o Hermes deve:

1. Confirmar recebimento (trace_id)
2. Aplicar **Técnica da Lupa** antes de executar se for plano/patch
3. Refinar **só** o que é do setor Hermes
4. Devolver relatório ao **Pivete** (Telegram @srver1bot / card Hermes)
5. Opcional: gravar lição com ferramenta `aprender` (categoria multi-agente-radio)
