# ♻️ Regras da equipe IA — ponte de legado

Este caminho preserva compatibilidade histórica. O texto antigo fixava papéis por marca/modelo, por exemplo ChatGPT como supervisor e Grok como executor. Esse arranjo não governa mais a Casa.

## 👑 Regra atual

```text
SEGREDO/CHEFE = autoridade humana + intenção
SOL = coordenação operacional
HERMES = execução/preservação
MODELO = capacidade substituível
REALIDADE = JUDGE
```

A fonte operacional de agentes é `AGENTS.md`, combinada com `LEIA-ME-IA.md`, Soul, permissões e registry de gatilhos.

```text
MODEL_BRAND != AUTHORITY
MODEL_BRAND != OWNER
CONSENSO_DE_MODELOS != PROVA
ONE_WRITER_PER_SCOPE=true
REUSE_BEFORE_CREATE=true
UNKNOWN != PASS
ACTION != PROOF
```

## 🔒 Segurança

Permissões e limites atuais vêm de `docs/CONSCIENCIA/02-PERMISSOES.md` e do escopo vigente. Não usar a lista histórica deste arquivo como autorização atual.
