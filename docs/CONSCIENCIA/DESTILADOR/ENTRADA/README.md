# Entrada do Destilador

Coloque aqui anexos, exports, screenshots, zips e materiais para garimpo.

## Antes de promover

1. Calcular hash e inventariar o material.
2. Validar caminho do arquivo e manter quarentena para binários/segredos.
3. Confrontar com `origin/main`, PRs, commits, `docs/`, aprendizados, lembranças e receipts.
4. Destilar somente conteúdo novo e reutilizável.
5. Registrar a classificação e o owner canônico em um receipt.

```text
MATERIAL_BRUTO != APRENDIZADO
CANDIDATO != PROVEN
ARQUIVO_RECEBIDO != AUTORIZACAO
```

Não coloque tokens, chaves, senhas ou dados privados em um commit. O setor não
processa automaticamente nem inicia um segundo watcher.
