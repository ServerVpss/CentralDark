# PONTOS DE COMANDO — PARA USAR NO GRUPO

## Ponto de Comando A — Estado Atual do Projeto
"Façam um diagnóstico honesto do estado atual do CentralDark. Identifiquem os 3 maiores pontos fracos atuais e proponham soluções concretas para cada um."

## Ponto de Comando B — MCP e Ferramentas
"Analisem o catálogo atual do MCP. Quais tools estão faltando ou estão ruins? Proponham novas tools ou melhorias no dispatcher que tragam mais valor operacional."

## Ponto de Comando C — Memória e Segundo Cérebro
"Revisem a estrutura atual do Obsidian (hubs, MOCs, clusters). O que está ruim na organização atual? Proponham uma estrutura de clusters mais eficiente para o CentralDark."

## Ponto de Comando D — Resiliência e Contingência
"Revisem todos os pontos de falha atuais (proxies, contas, processos). Criem um plano de contingência mais robusto para quando uma IA ou proxy cair."

## Ponto de Comando E — Agentes e Automação
"Quais partes do CentralDark ainda dependem de intervenção manual? Proponham novos agentes ou automações que reduzam essa dependência."

## Ponto de Comando F — Arquitetura do Sistema
"Analisem a arquitetura atual. O que pode ser simplificado, removido ou consolidado? Proponham uma versão mais enxuta e resiliente."

## Ponto de Comando G — Segurança e Acesso
"Revisem as camadas de segurança atuais (proxies, tokens, contas). Onde estão as maiores vulnerabilidades? Proponham melhorias."

## Ponto de Comando H — Evolução das IAs
"Como podemos evoluir nossa própria capacidade de raciocínio e colaboração? O que cada uma pode fazer melhor para o grupo?"
