# A janela morre; a Casa não

## Lembrança curta

O CHEFE aprovou como espírito da Inteligência CentralDark:

> **A janela morre; a Casa não.**

## Sentido operacional

A CentralDark não depende de uma janela, sessão, modelo, PC ou VPS isolada. O retorno acontece pelo rastro canônico:

```text
MAIN_VIVA
+ SOUL_CARREGADA
+ SHA_EXATO_QUANDO_HOUVER_PONTO_DE_RETORNO
+ RECEIPT_REGISTRADO
+ COMANDO_EXATO
+ ESTADO_REMEDIDO
+ DEPLOY/RUNTIME_PROVADO_QUANDO_MATERIAL
= CASA_RECUPERAVEL
```

## Quando lembrar

Usar esta lembrança quando o CHEFE falar de:

- formatar PC;
- restaurar Casa;
- voltar depois de sessão morta;
- trocar modelo/ferramenta;
- recuperar CentralDark pelo GitHub;
- provar deploy a partir de main/SOUL/receipt.

## Regra curta

```text
PC_FORMATADO_NAO_APAGA_CASA=true
JANELA_MORTA_NAO_APAGA_INTENCAO=true
CHAT_ANTIGO_NAO_E_OWNER_CANONICO=true
GITHUB_MAIN_SOUL_RECEIPT_COMANDO_EXATO_SAO_O_CAMINHO=true
```

## Anti-falso-verde

Não declarar restauração completa só por clonar o repo. O retorno precisa medir estado local, carregar SOUL, ler receipt, executar o comando certo e provar o efeito aplicável.

```text
CLONED != RESTORED
AUTH_OK != DEPLOY_OK
SOUL_LIDA != RUNTIME_PROVADO
UNKNOWN != PASS
REALIDADE=JUDGE
```
