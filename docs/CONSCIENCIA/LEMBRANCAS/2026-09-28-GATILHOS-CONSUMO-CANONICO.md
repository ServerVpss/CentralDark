# 🪬 Lembrança — Gatilhos de consumo canônico

## Selo

```text
CHEFE=nada morre no chat
CANONICO=ServerVpss/CentralDark@main
APRENDIZADO=#80
TEMA=ter_ferramenta_ponteiro_unknown_medivel
STATUS=LEMBRANCA_DURAVEL
```

## Essência preservada

O erro corrigido não foi falta de ferramenta. Foi tratar ferramenta disponível como se não existisse, ler ponteiro como se fosse fonte e usar `UNKNOWN` onde havia rota de medição.

Esta lembrança existe para o próximo motor acordar já sabendo: antes de responder sobre CentralDark, consumir a main e o aprendizado canônico.

## Regra prática

```text
CONECTORES_ATIVOS
→ MAIN_READ
→ CARTAO_DE_BOOT
→ APRENDIZADOS_SEARCH
→ EXECUTAR/MEDIR
→ RESPONDER
```

## Três travas

1. **TER FERRAMENTA != TER MEDIDO**
   - Inventariar conectores e tentar rota autorizada antes de declarar falta de capacidade.
   - Falta de uma ferramenta em um corpo não prova falta da capacidade no organismo inteiro.

2. **PONTEIRO != FONTE**
   - Texto colado pelo CHEFE pode ser ponteiro.
   - A main vence o chat, o print, o cache e a memória.
   - Abrir os owners citados antes de responder.

3. **UNKNOWN_MEDÍVEL = FALHA DE MÉTODO**
   - `UNKNOWN` só é honesto quando não existe meio de medir naquele momento.
   - Se a ferramenta existe e não foi usada, é preguiça com roupa de prudência.
