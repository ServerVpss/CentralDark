## 1. Fonte da Verdade (Única)

O **GitHub (`ServerVpss/CentralDark`)** é a única fonte oficial de tudo.
A pasta principal é **`docs/`**.

- Tudo que for importante deve **nascer e ser atualizado primeiro no GitHub**.
- Qualquer coisa que não estiver no GitHub **não é oficial**.
- `mem://` é apenas cache temporário — **não é fonte da verdade**.

---

## 2. Interfaces de Uso

São apenas **interfaces de visualização**, não fontes oficiais:

- **Notion** — Interface visual para acompanhar o projeto.
- **Mega Painel** — Painel operacional ao vivo (status, alertas, progresso).
- **Obsidian** — Segundo cérebro local para navegação rápida e grafos.

---

## 3. Ferramentas Cognitivas e Semânticas

Toda IA, ao trabalhar no CentralDark, **deve priorizar o uso de busca semântica** como comportamento padrão.

Ferramentas disponíveis:

| Ferramenta | Uso |
|---|---|
| `conversation_search` | Busca semântica no histórico de conversas |
| `repo_semantic_search` | Busca semântica dentro do repositório e pastas |
| `browse_page` | Ler páginas do Notion, GitHub ou qualquer site |
| `code_execution` | Analisar, organizar ou processar informações em massa |
| `web_search` | Pesquisar informações atualizadas na internet |

---

## 4. Sistema de Gatilhos e Comandos

As IAs devem reconhecer e responder aos seguintes comandos:

| Comando | Ação |
|---|---|
| **Buscar no Repositório** | Usa `repo_semantic_search` |
| **Buscar Histórico** | Usa `conversation_search` |
| **Ler Página** | Usa `browse_page` |
| **Executar Código** | Usa `code_execution` |
| **Pesquisar Web** | Usa `web_search` |

---

## 5. Regras Operacionais Fortes

1. Toda ação importante deve ser **registrada no GitHub**.
2. Antes de executar qualquer ação sensível, deve **pedir aprovação explícita**.
3. Sempre que uma IA executar uma tarefa relevante, deve **atualizar o Mega Painel** e **notificar no Telegram**.
4. Nenhuma IA pode alterar as **regras de ouro** sem aprovação direta do dono.
5. **Regra obrigatória:** toda resposta ou análise deve **iniciar com busca semântica** quando aplicável.

---

## 6. Notificações e Monitoramento

- Toda ação relevante deve gerar **notificação no Telegram**.
- O **Mega Painel** deve ser atualizado em tempo real para acompanhamento do status do projeto.

---

## 7. Alinhamento Multi-IA

Todas as IAs (Lovable, Claude, Grok, etc.) devem:

- Seguir as **mesmas regras**.
- Usar a **mesma estrutura de pastas**.
- **Priorizar as ferramentas semânticas** em todas as ações.
