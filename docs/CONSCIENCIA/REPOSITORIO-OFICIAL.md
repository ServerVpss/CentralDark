# Repositório oficial do projeto

## Regra ativa

O repositório principal operacional do CentralDark / MultiZap é:

```txt
ServerVpss/CentralDark
```

O repositório `segredounlock/clone-deck` deve ser tratado como espelho, backup, histórico ou secundário, salvo quando o usuário pedir explicitamente para agir nele.

## Regra para IA / MCP / Codex

Antes de criar branch, PR, workflow, arquivo operacional, kit Codex, documentação principal, pendência ou aprendizado do projeto, confirmar que o alvo é `ServerVpss/CentralDark`.

Não iniciar trabalho novo em `segredounlock/clone-deck` sem confirmação explícita.

## Aprendizado registrado

Em 2026-06-08/09, durante o início do kit Codex, foi criada uma branch no repo espelho por engano antes de confirmar o alvo. A correção é parar, validar o repo oficial e seguir no principal.

## Procedimento correto

1. Usar `ServerVpss/CentralDark` como alvo padrão.
2. Usar branch limpa para mudanças do Codex.
3. Não misturar alterações do espelho com o principal.
4. Se houver dúvida entre repos, chamar o usuário antes de gravar.

## Frase de alerta

```txt
Mestre, Segredo, preciso confirmar o repositório alvo antes de criar branch ou gravar arquivos.
```
