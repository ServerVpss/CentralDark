# Artefatos — CentralDark

> **Propósito:** Repositório de fragmentos de conhecimento, mapas, decisões visuais e artefatos de construção do ecossistema CentralDark.
> Criado em: 29/06/2026

---

## O que vai aqui

Esta pasta armazena fragmentos que registram a **evolução do CentralDark** — não são documentos operacionais, mas sim registros do processo de construção.

| Tipo de artefato | Exemplos |
|---|---|
| **Mapas conceituais** | Diagramas de arquitetura em Markdown/ASCII |
| **Resumos de decisão** | Versões compactas de decisões longas |
| **Fragmentos de conhecimento** | Trechos que não cabem em nenhum outro arquivo mas são valiosos |
| **Snapshots de estado** | Fotografias do estado do sistema em momentos importantes |
| **Rascunhos aprovados** | Versões finais de prompts, flows ou configurações criadas iterativamente |
| **Mapas de evolução** | Linha do tempo de como algo mudou ao longo do tempo |

---

## O que NÃO vai aqui

- Regras operacionais → `01-IDENTIDADE-E-REGRAS/`
- Pendências ativas → `docs/PENDENCIAS.md`
- Decisões formais → `08-HISTORICO-DECISOES.md`
- Relatórios de sync → `docs/RELATORIOS/`
- Código ou scripts → `scripts/` na raiz do projeto

```
AAAA-MM-DD_TEMA_descricao-curta.md
```

Exemplos:
