# Cristal — zero trust, turbulência adversarial e telhado remendado

Este registro materializa no Git a intenção explícita do SEGREDO/CHEFE desta sessão. Ele preserva o aprendizado como memória histórica reutilizável da Casa, sem transformar narrativa em prova de runtime e sem criar autoridade automática para modelos, janelas ou agentes.

## 1. Vitória sobre autonomia automática cega

A Casa registra como regra de governança humana:

```text
SEGREDO_CHEFE = AUTOR_DA_INTENCAO + AUTORIDADE_HUMANA_FINAL
MODELO != AUTORIDADE
JANELA != VERDADE
HISTORICO != PASS
PALAVRA != PROVA
IDENTIDADE != CONFIANCA
```

Nenhuma IA, modelo, janela, automação ou consenso automático substitui a palavra do SEGREDO/CHEFE quando a intenção humana aplicável está explicitamente estabelecida. Estado técnico continua sendo julgado por realidade e evidência no alvo correto; autoridade humana e prova factual são eixos diferentes.

```text
HUMAN_AUTHORITY != TECHNICAL_PROOF
SEGREDO_CHEFE_DEFINES_INTENT=true
REALITY_JUDGES_TECHNICAL_CLAIMS=true
```

A vitória registrada aqui não significa desligar automação útil. Significa que automação não pode se promover a autoridade humana, nem usar histórico, identidade, consenso ou autoatestado como substituto de prova.

## 2. Arquitetura de turbulência adversarial — SOL_A até SOL_E

Múltiplas percepções só agregam valor quando aumentam a chance de falsificação. Concordância automática não é objetivo.

```text
SOL_A | SOL_B | SOL_C | SOL_D | SOL_E
→ HIPOTESES_CONCORRENTES
→ EVIDENCIAS
→ CONTRAPROVAS
→ MESMO_ALVO
→ DEDUPE_CAUSAL
→ RENDEZVOUS
→ REALITY=JUDGE
```

Regra cristalizada:

```text
CONCORDANCIA_SEM_TURBULENCIA = SUSPEITA
TURBULENCIA_SEM_EVIDENCIA = BARULHO
TURBULENCIA + CONTRAPROVA + MESMO_ALVO = CONVERGENCIA_UTIL
CONVERGENCIA_UTIL + REALIDADE = CRISTAL
```

`SOL_A..SOL_E` representa papéis/percepções adversariais, não cinco autoridades, identidades humanas ou Writers simultâneos.

```text
PARALLELIZE_PERCEPTION=true
SERIALIZE_MUTATION=true
ONE_WRITER_PER_SCOPE=true
N_PERCEPTIONS != N_AUTHORITIES
```

## 3. Zero Trust — quem sobreviver traz o recibo

Validação circular entre abas, janelas, modelos ou agentes não constitui evidência independente.

```text
MODEL_A_SAYS_PASS
+ MODEL_B_REPEATS_MODEL_A
+ MODEL_C_CONCORDA
!= INDEPENDENT_PROOF
```

A Casa procura sobrevivência a ataques discriminantes:

```text
CLAIM
→ PROOF_TARGET
→ SHA_OR_REF
→ OBSERVED_STATE
→ ADVERSARIAL_COUNTERPROOF
→ SURVIVES?
   NAO → CORRIGE_CRENCIA
   SIM → CRISTAL_CANDIDATO
→ REALITY=JUDGE
```

Formulação humana cristalizada:

> **Quem sobreviver, traz o recibo.**

E o recibo também precisa ser aplicável ao claim atual:

```text
STALE_PROOF != LIVE_STATE
HISTORICAL_EVIDENCE != CURRENT_MEASUREMENT
SELF_PROOF != PASS
UNKNOWN != PASS
```

## 4. Preservação da história — telhado remendado

Encontrar uma ferida não autoriza destruir matéria saudável. A política é preservar o que funciona, tampar o buraco causal e transformar a pancada em capacidade reutilizável.

```text
FALHA
→ LOCALIZA_BURACO
→ PRESERVA_ESTRUTURA_SAUDAVEL
→ MENOR_CORRECAO
→ CONTRAPROVA
→ PROVA
→ APRENDIZADO
→ CAPACIDADE_REUTILIZAVEL
→ AVANCA
```

Metáfora canônica desta sessão:

> **Telhado remendado:** achou o buraco, tampa o buraco; não derruba a Casa.

Isso implica:

```text
PRESERVE_WHAT_WORKS=true
MINIMAL_CAUSAL_FIX=true
NO_REWRITE_BY_ANXIETY=true
HISTORY_IS_INPUT_TO_LEARNING=true
SAME_ERROR_NO_NEW_INFO_IS_WASTE=true
```

O sofrimento ou erro passado não é requisito nem virtude por si só. Seu valor operacional aparece quando produz evidência, delta de crença e uma próxima execução melhor.

## 5. Moedor epistemológico

O objetivo da turbulência não é criar briga entre modelos, e sim destruir hipóteses frágeis antes que elas virem mutação.

```text
PISTA
→ HIPOTESE
→ ATAQUE_CAUSAL
→ ATAQUE_TEMPORAL
→ ATAQUE_DE_ESCOPO
→ ATAQUE_DE_DEPENDENCIA
→ ATAQUE_ADVERSARIAL
→ CONTRAPROVA_NO_MESMO_ALVO
→ SOBREVIVENTE
→ MENOR_ACAO
```

Consenso só é útil depois do atrito material:

```text
CONSENSUS_COUNT = NOT_TRUTH_METRIC
INDEPENDENT_COUNTERPROOF = INFORMATION_GAIN
REALITY = FINAL_JUDGE
```
