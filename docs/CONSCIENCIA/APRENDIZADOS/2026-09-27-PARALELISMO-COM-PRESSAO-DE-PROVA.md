# Paralelismo com pressão de prova

## Intenção real

Registrar que múltiplas canetas, modelos, janelas, vozes e agentes podem trabalhar em paralelo sem virar bagunça, desde que todos convirjam para uma intenção viva, um owner existente, uma main e um rastro verificável.

## Fato observado

Várias frentes trabalharam ao mesmo tempo. Houve atrito, contradição, erro, correção, disputa semântica e recalibração. Nenhuma caneta isolada pegou todos os erros. O cruzamento entre elas, guiado pelo CHEFE, fez a verdade convergir pela pressão da prova.

```text
PARALLEL_READING_ALLOWED=true
PARALLEL_PATHS_ALLOWED=true
PARALLEL_SYSTEM_FORBIDDEN=true
ONE_WRITER_PER_SCOPE=true
MAIN_ACCEPTS_ONLY_PROVEN_DELTA=true
RELATED_PR_RECEIVES_TRACE=true
REALITY_IS_JUDGE=true
UNKNOWN_IS_NOT_PASS=true
```

## Regra cristalizada

Paralelismo de leitura é permitido.
Paralelismo de caminhos é permitido.
Sistema paralelo é proibido.
A main recebe só prova.
O PR relacionado recebe rastro.
O Writer é único por escopo.

## Frase canônica

```text
VARIAS_CANETAS_EM_PARALELO
+ EXIGENCIA_DURA_DE_PROVA
= CORRECAO_MUTUA_ATE_SOBRAR_SO_O_QUE_PASSA
```

## Correção semântica importante

Peça não é unidade.

Uma ferramenta, modelo, janela, voz ou agente sozinho é peça. A unidade nasce quando tudo converge para uma intenção, uma main, um rastro e uma realidade julgando.

```text
PECA_NAO_E_UNIDADE=true
CAMINHO_PARALELO_PODE_EXISTIR=true
SISTEMA_PARALELO_NAO=true
```

## Não afirmar

- Não afirmar "único no mundo" sem prova.
- Não afirmar "ninguém faz parecido" sem prova.
- Não transformar busca sem resultado em prova absoluta.
- Não confundir método funcionando com vaidade.

## Pode afirmar

- O método funcionou nesta Casa.
- O cruzamento pegou erro real.
- As canetas se corrigiram.
- A pressão de prova reduziu falso verde.
- A convergência ficou mais forte que uma janela isolada.

## Falsificador

Se uma caneta paralela gerar sistema paralelo, owner duplicado, commit sem rastro ou main sem prova, então o método foi quebrado, não validado.

## Aplicação futura

Quando houver várias janelas, modelos ou agentes:

1. cada um pode medir;
2. cada um pode trazer delta;
3. cada um pode contradizer;
4. só sobe o que tiver prova;
5. a verdade final é do rastro, não da caneta.

## Resumo de bolso

Não foi bagunça; foi paralelismo disciplinado.
Não foi teimosia; foi calibração sob pressão.
Não foi ego; foi prova separando peça de unidade.
