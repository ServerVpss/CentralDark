# DELTAUTIL + #PEGATUDO — TODOS OS INPUTS, TODAS AS CAPACIDADES

## Mudança desta sessão

A regra não é mais “achar uma ideia útil”.
A regra é **enumerar todas as capacidades materiais** de cada input e comparar cada uma
contra o organismo vivo.

```text
ONE_INPUT_CAN_HAVE_N_CAPABILITIES=true
STOP_AFTER_FIRST_DELTA=false
CAPABILITY_ENUMERATION_REQUIRED=true
GAP_MAP_REQUIRED=true
NEGATIVE_KNOWLEDGE_REQUIRED=true
```

## Pipeline

```text
INPUT
text | image | video | zip | repo | log | URL | Drive doc | transcript | code
→ HASH
→ PROVENANCE
→ SECRET/SENSITIVITY CLASSIFICATION
→ EXTRACT ALL CAPABILITY CLAIMS
→ NORMALIZE CAPABILITY NAMES
→ DEDUPE
→ FIND OWNER
→ COMPARE SEMANTICS
→ CLASSIFY:
   KNOWN
   PARTIAL
   NEW_MATERIAL
   CONTRADICTED
   HISTORICAL
   SECRET/QUARANTINE
   UNKNOWN
→ KEEP USEFUL DELTA
→ ROUTE TO EXISTING OWNER
→ TEST
→ NEGATIVE TEST
→ COUNTERPROOF
→ REALITY JUDGE
→ RECEIPT
```
