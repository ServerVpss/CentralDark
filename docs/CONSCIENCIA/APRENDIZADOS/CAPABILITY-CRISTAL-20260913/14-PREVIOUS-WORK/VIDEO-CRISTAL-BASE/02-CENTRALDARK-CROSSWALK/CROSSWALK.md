# Crosswalk — vídeo → CentralDark

| Conceito do vídeo | Owner/peça CentralDark | Regra de absorção |
|---|---|---|
| Context windows | memória em camadas + compactação + receipts | preservar prova, owner e next cursor |
| CLAUDE.md | CONSCIÊNCIA / regras canônicas / skills | reutilizar owner textual existente |
| Workflows | Hermes + operational method | workflow não vira novo core |
| Deploy | GitHub Actions / VPS / deploy status | MERGED != DEPLOYED |
| RAG | semantic fabric / retrieval / BRAIN | vetor não é autoridade |
| APIs & MCPs | MCP CentralDark + Hub | um MCP público, tools por dentro |
| Skills | skill fabric | skill nova só se owner não existir |
| Sub-agents | executores Hermes | percepção paralela, mutação serializada |
| Agent Teams | SOL + N executores | one writer per scope |
| Browser automation | Desktop/Screenpipe/UIA/Browser tools | registrar assinatura e rastro |
| GitHub/worktrees | repo canônico + branches | main é destino, não substitui runtime proof |
| Delivery | evidence + contrap prova + receipts | ação não é prova |

## Delta útil dominante

O valor do vídeo para a CentralDark não está em “instalar Claude Code”.
Está em reforçar padrões que a Casa já usa:

1. contexto persistente e recuperável;
2. separação entre workflow, tool e owner;
3. skills com carregamento sob demanda;
4. subagentes isolados para reduzir ruído;
5. times com territórios claros;
6. automação de navegador com persistência e evidência;
7. RAG/embeddings como recuperação, nunca autoridade;
8. GitHub como trilha de mudança, não como prova de runtime;
9. entrega por ciclos observáveis.
