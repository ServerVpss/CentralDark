# GENERATIVE CAPABILITY ACQUISITION

A CentralDark deve ser capaz de procurar uma capability ausente e gerar **candidato**,
sem transformar geração em autoridade.

```text
NEED
→ DISCOVER LOCAL
→ FOUND_SUFFICIENT       → REUSE
→ FOUND_PARTIAL          → EXTEND
→ NOT_FOUND              → RESEARCH
→ RESEARCH_RESULTS       → SYNTHESIZE CANDIDATE
→ SANDBOX
→ STATIC / SECURITY CHECK
→ FUNCTIONAL TEST
→ NEGATIVE TEST
→ COUNTERPROOF
→ CONSUMER PROOF
→ REALITY JUDGE
→ PROMOTE INTO EXISTING OWNER
→ BENCHMARK
→ RECEIPT
```

## Composição antes de criação

Exemplo vídeo:

```text
NEED=entender vídeo
→ youtube_transcript?
→ frame extractor?
→ image embeddings?
→ semantic index?
→ trace?
→ graph?

Se 4/6 já existem:
não criar video-brain.
fechar somente as 2 lacunas.
```
