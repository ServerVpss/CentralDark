# Crítica visual das referências do CHEFE

## O que é forte

- impacto visual alto;
- visão macro de densidade e agrupamentos;
- navegação espacial/zoom ajuda a perceber zonas;
- distribuição radial dá leitura imediata de "centro vs periferia";
- ótima base para uma lente investigativa.

## O que NÃO está provado pela aparência

- significado dos nós;
- significado das linhas;
- causalidade;
- provenance;
- freshness;
- owner;
- confidence;
- se o centro é entidade real ou mero efeito de layout.

## Feridas visuais

1. hairball: muitas linhas simultâneas;
2. núcleo recebe/parece receber conexões demais;
3. pontos pequenos sem prioridade semântica;
4. densidade pode virar estética sem explicação;
5. distância visual pode ser confundida com importância;
6. sem legenda fixa, cor vira decoração;
7. relação causal e referência parecem equivalentes.

## Resposta CentralDark

- núcleo = lente virtual protegida;
- cada nota = 1 primary spine;
- relações extras = sob demanda;
- anéis = hops causais;
- sectors = communities;
- overflow = novo anel;
- linhas que cruzariam o núcleo = Bézier tangencial;
- estado e relação usam canais visuais separados;
- Agentic Lens ranqueia feridas mas não escreve.
