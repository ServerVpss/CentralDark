# Prompt & Behavior Engineering — capabilities úteis

Absorver sem criar um “prompt brain” paralelo.

```text
SYSTEM / HOUSE
→ invariantes estáveis

SKILL / CAPABILITY
→ conhecimento operacional especializado

RUNTIME CONTEXT
→ estado vivo

HOOK / GATE
→ garantia determinística

MEMORY / DREAM REVIEW
→ aprendizado elegível
```

## Deltas úteis

1. Prompt Mínimo Viável.
2. Tool Contract explícito: trigger, prerequisites, exclusions, batching, chaining.
3. Rule-with-why.
4. Toda regra material deve possuir um teste que falharia sem ela.
5. Prompt onion detector: detectar camadas redundantes.
6. Emphasis inflation detector: detectar ALWAYS/NEVER/URGENT em excesso.
7. Diff semântico de comportamento.
8. Behavior regression harness antes de promover prompt/skill.
9. Consolidação periódica sem perda de comportamento.
10. Separar disposição do modelo de garantias duras em hooks/gates.
