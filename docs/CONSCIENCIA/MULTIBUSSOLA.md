# !MULTIBUSSOLA — comando oficial da CentralDark

`!MULTIBUSSOLA` é um gatilho oficial da Casa, no mesmo nível de entrada operacional de `#ACORDAR` e `!CALIBRAR`, porém com função diferente:

```text
#ACORDAR
= recuperar o estado real

!CALIBRAR
= alinhar interpretação + papel + escopo + tools + prova

!MULTIBUSSOLA
= observar o alvo por todos os eixos e referenciais materiais,
  cruzar contraprovas, remedir o estado no final e fechar somente em fixed point
```

O comando **não cria outro agente, skill, cérebro, memória, promotor ou orquestrador**. Ele reutiliza `#ACORDAR`, `!CALIBRAR`, Metacognição Operacional, MetaLupa, Meta Menos É Mais, owners/prova existentes e o Writer vigente.

```text
GLOBAL_HOUSE_COMMAND=!MULTIBUSSOLA
MULTIDIRECTIONAL_ANALYSIS=true
MULTIREFERENCE_ANALYSIS=true
TEMPORAL_REMEASUREMENT=true
CAUSAL_COUNTERPROOF=true
SPATIAL_FRAME_SHIFT=true
ADVERSARIAL_BYPASS_HUNT=true
META_SELF_APPLICATION=true
REVISITED_REVIEW=true
FIXED_POINT_REQUIRED=true
NEW_ORCHESTRATOR=false
NEW_AGENT=false
NEW_AUTHORITY=false
ONE_WRITER_PER_SCOPE=true
UNKNOWN_NEVER_PASS=true
REALITY_IS_JUDGE=true
```

## 1. Sintaxe e ativação

Aceitar sem sensibilidade a maiúsculas/minúsculas:

```text

!MULTI-BUSSOLA
!MULTIBÚSSOLA
```

Quando o comando vier junto de `#ACORDAR` e/ou `!CALIBRAR`:


## 2. Matriz direcional oficial

```text

              CAUSA / ORIGEM
                    │
              ↖     │     ↗
                 \  │  /
                  \ │ /
← FONTE ─────────── ✣ ─────────── CONSUMIDOR →
                  / │ \
                 /  │  \
              ↙     │     ↘
                    │
                    ↓
              EFEITO / ESTADO
```

```text
↓
```

### → FORWARD — fonte → futuro / blast radius

```text

→ CONSUMIDOR
→ DEPENDENTES
→ DEPENDENTES DOS DEPENDENTES
→ BLAST RADIUS
```

Pergunta: `Se isto mudar, quem sente depois?`

### ← REVERSE — resultado → origem

```text

← PRÉ-REQUISITOS
← PRODUTORES
← DEPENDÊNCIAS
← OWNER/FONTE
```

Pergunta: `Para este resultado existir, o que precisava ser verdade antes?`

### ↔ ROUND-TRIP — ida e volta / contramão

Cruzar, quando aplicável:

```text

FONTE ↔ CONSUMIDOR
REQUEST ↔ RECEIPT
CLAIM ↔ PROVA
ANTES ↔ DEPOIS
INPUT ↔ OUTPUT
AUTORIDADE ↔ AÇÃO
ARTEFATO ↔ EFEITO
```

Pergunta: `Foi e voltou preservando significado, escopo e autoridade?`

### ↘ ↗ ↙ ↖ TRANSVERSAIS

As diagonais atravessam camada, domínio, tempo e superfície sem confiar somente na hierarquia óbvia:

```text
↘ TOP/ORIGEM → CROSS-LAYER → EFEITO LATERAL
↗ EFEITO LATERAL → CROSS-LAYER → ORIGEM
↙ ESTADO/EFEITO → HISTÓRICO/OWNER ALTERNATIVO
↖ EVIDÊNCIA LATERAL → CAUSA/OWNER
```

Exemplos de travessia:

```text
INTENÇÃO ↘ PR ↘ WORKFLOW ↘ RUNTIME
EFEITO ↗ LOG ↗ WORKFLOW ↗ PR ↗ INTENÇÃO
ZIP ↗ PADRÃO EXTERNO ↘ CAPACIDADE CENTRALDARK ↖ CONSUMIDOR
```

### ✣ RENDEZVOUS — cruzamento total

Todos os achados materiais convergem no centro:

```text

          ↓
          ✣
          ↓
NORMALIZE

```

Não existe votação de modelos. Conflito no mesmo alvo exige teste discriminante ou permanece `UNKNOWN`. A realidade é Judge.
