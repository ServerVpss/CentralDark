# Lembrança — Micro-deploy Contínuo por PASS Comprovado

Aprendizado durável cristalizado: quando uma frente comprova PASS determinístico em um escopo material, ela não deve esperar perfeição global para avançar esse escopo.

```text
QUALQUER_PASS_COMPROVADO
→ MICRO_DEPLOY_DO_ESCOPO_AFETADO
→ HEALTH_OU_PROVA_RUNTIME
→ RECEIPT_PR_MAE
→ NEXT_TIK_TAK
```

## O que esta lembrança corrige

- Evita paralisia por pendência paralela não relacionada.
- Evita falso bloqueio global quando um escopo local já está provado.
- Impede que badge visual, `action_required`, documento ou merge sejam tratados como runtime executado.
- Mantém `UNKNOWN != PASS` e `MERGED != DEPLOYED` como travas permanentes.

## Como usar

Toda IA, bot, Hermes, MCP, workflow ou agente autorizado deve:

1. preservar a missão atual;
2. medir o escopo afetado;
3. promover somente o escopo com PASS comprovado;
4. medir health/prova runtime quando houver runtime;
5. registrar receipt no PR-MÃE ou owner aplicável;
6. continuar com `NEXT_TIK_TAK`.

## Travas

```text
PASS_VISUAL_BADGE_ONLY=false
ACTION_REQUIRED_IS_NOT_PASS=true
UNKNOWN_IS_NOT_PASS=true
LOCAL_PROOF_WITH_RUNTIME_SCOPE_REQUIRES_RUNTIME_PROOF=true
NO_SECRET_LEAK=true
NO_BLIND_RESET=true
NO_BLIND_PULL_OVER_DIRTY_RUNTIME=true
```

## Frase curta

> PASS comprovado anda. UNKNOWN espera prova. Falso-verde não passa.
