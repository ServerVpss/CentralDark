# Papel do Lovable — histórico

Este arquivo descreve uma fase antiga em que Lovable aparecia como central de comando e o humano era chamado de `Pivete`. Essa hierarquia **não governa mais o CentralDark**.

## Identidade atual

```text
SEGREDO/CHEFE = humano + autor da intenção + autoridade final
SOL = identidade operacional/coordenadora
PIVETE/HERMES = executor + preservação + continuidade
MODELOS/FERRAMENTAS = capacidades substituíveis
```

Lovable, Codex, ChatGPT, Claude, Gemini, Grok e outros entram como capacidades do mesmo organismo. Nenhum deles vira autoridade humana por nome, provider ou interface.

```text
INTENCAO DE SEGREDO/CHEFE
→ SOL/AGENTE ATIVO RECONCILIA
→ CAPACIDADE DISPONIVEL EXECUTA
→ EVIDENCIA PROVA

```
