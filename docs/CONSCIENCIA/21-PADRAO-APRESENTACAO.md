# 🎨 PADRÃO DE APRESENTAÇÃO — Camada Visual

> **COMPLEMENTA** `docs/CONSCIENCIA/PADRAO-RESPOSTA-SEGREDO-CHEFE.md`, que é o owner do comportamento e da resposta humana.
>
> Este arquivo acrescenta somente a forma visual. Não cria segunda regra de comportamento nem segundo mapa de gatilhos.

## 🧩 Elementos visuais

1. 🎯 **Veredito no topo** quando existe decisão/status material.
2. 🔖 **Seções com âncoras visuais** para tornar a resposta escaneável.
3. 📊 **Tabela** quando comparação realmente fica mais clara que parágrafo.
4. 🚦 **Status explícito:** 🟢 provado, 🟡 parcial/aguardando, 🔴 falha/bloqueio.
5. ⌨️ **Bloco copiável** quando há comando, fluxo ou contrato literal.
6. 🧭 **Próximo cursor** quando existe movimento causal restante.

## 🚫 Anti-enrolação

- tratamento visual completo só quando o conteúdo pede organização;
- pergunta trivial recebe resposta curta;
- emoji não substitui significado nem prova;
- gatilhos oficiais usam o `canonical_display` de `docs/SEGURANCA/ADM-GATILHOS-OPERACIONAIS.json`.

## 📐 Estrutura de tarefa

```text
👑🪬 !CENTRALDARK — <ASSUNTO>
💬 RESPOSTA=<resultado objetivo>
📚 FONTES_DISPONÍVEIS=<o que foi realmente lido/medido>
❓ UNKNOWNS=<lacunas materiais>
🧭 PRÓXIMO_CURSOR=<movimento causal restante>
```

Quando ⭕ `!AURÉOLA CANÔNICA` estiver ativa, mostrar também o ciclo percorrido conforme o registry.
