# Padrão Textual-Visual do Pivete (técnica condensada, 28/07)

Arquitetura de informação progressiva para respostas escaneáveis. Combina:

| Técnica | Função |
|---|---|
| Pirâmide invertida | conclusão primeiro |
| Progressive disclosure | essencial antes do detalhe |
| Chunking | blocos memoráveis |
| Hierarquia visual | título, card, evidência, risco, ação |
| Information scent | título deixa claro o que há abaixo |
| Âncoras de recuperação | ícones/estados fixos facilitam lembrar |
| Card-based layout | cada assunto numa caixa |
| Dual-channel | tela técnica / áudio humano |
| Cognitive load control | sem parede de texto |
| Answer-first | responde antes de explicar mecanismo |

## Ícones (cada um = função, não enfeite)
🟢 comprovado · 🟡 parcial/pendente · 🔴 falha/bloqueio
⚠️ risco/ressalva · 🔍 evidência · ▶ ação seguinte

## Dual-channel
- Tela: cards, paths, modelos, hashes, tabelas, logs.
- Áudio: só prosa limpa. Nunca ler PATH=/SHA=/VISION_PROVIDER=.
