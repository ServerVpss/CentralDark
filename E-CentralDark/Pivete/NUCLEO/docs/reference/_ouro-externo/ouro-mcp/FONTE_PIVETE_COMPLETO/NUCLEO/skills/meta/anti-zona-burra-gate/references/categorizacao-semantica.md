# Categorização Semântica — Binários + Palavras Recuperatórias

Padrão ensinado pelo Pivete (06/08/2026): **não cortar, separar semanticamente**.

## Regra
Ao salvar conhecimento (skill, nota, aula, transcrição de imagem):
1. NUNCA cortar o texto original para caber em formato
2. Separar em duas categorias precisas:
   - BINÁRIOS — gates lógicos (SIM/NÃO, OBRIGATÓRIO/PULADO)
   - PALAVRAS SEMÂNTICAS RECUPERATÓRIAS — termos-chave exatos para busca futura
3. Não duplicar entre as duas listas

## Exemplo de aplicação (aula zona-burra)

### BINÁRIOS (gates)
```
EVIDENCIA_EXISTENTE = SIM | NÃO
STRING_LITERAL_ACHADA = SIM | NÃO
FUNCAO_EXISTENTE = SIM | NÃO
RESULTADO_LITERAL_AUSENTE ≠ FUNCAO_INEXISTENTE
```

### PALAVRAS SEMÂNTICAS RECUPERATÓRIAS
```
- visão de túnel (tunnel vision)
- lost in the middle (arXiv 2307.03172)
- MAPA DE IDENTIDADES: SOL = GuardiaoCasa = coordenadora local
- Dreaming (OpenAI 03/06/2026)
```

## Por que funciona
- Binários = decisão rápida
- Palavras = busca semântica futura
- Texto original = preservado
- Zero duplicação
