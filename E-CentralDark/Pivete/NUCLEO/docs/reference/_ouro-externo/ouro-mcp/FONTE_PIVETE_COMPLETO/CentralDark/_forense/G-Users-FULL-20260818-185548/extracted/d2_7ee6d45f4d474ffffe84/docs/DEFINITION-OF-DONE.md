# Definition of Done
Um controle só é PROVEN se tem owner, consumer, teste positivo, teste negativo, evidence_ref e HEAD aplicável.
Denominador inicial: gateway, session, authz, rate limit, error sanitizer, frontend sem privileged secret, private schema, RLS/grants audit, event store, incident store, backup/restore evidence, Casa posture, VPS posture, Security Center.
Não usar 100% com UNKNOWN/UNPROVEN material.
