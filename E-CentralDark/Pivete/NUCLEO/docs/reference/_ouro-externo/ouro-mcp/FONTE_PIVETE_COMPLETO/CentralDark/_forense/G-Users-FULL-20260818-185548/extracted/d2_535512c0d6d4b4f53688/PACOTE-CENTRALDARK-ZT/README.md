## Como usar

1. Coloque a pasta `PACOTE-CENTRALDARK-ZT` no local do NÚCLEO (ex: `E:\CentralDark\Pivete\NUCLEO\`).
2. Abra `memoria/` no Obsidian.
3. Leia `zero-trust/PROTOCOLO-ZERO-TRUST.md` antes de qualquer extensão.
4. Os tools de memória já estão prontos para o Executor.
5. Browser-use é opcional e só entra sob especificação explícita.
