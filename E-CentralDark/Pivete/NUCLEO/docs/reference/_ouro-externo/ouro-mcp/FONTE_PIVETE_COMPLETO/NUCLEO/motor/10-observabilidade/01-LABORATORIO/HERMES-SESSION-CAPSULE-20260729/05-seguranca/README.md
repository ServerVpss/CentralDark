# CENTRALDARK — GUARDIÃ DA CASA

## Sistema Nervoso Operacional da Casa

A Guardiã da Casa é a camada sensorial da CentralDark. Ela não manda, não escreve no lugar do Writer e não aprova a própria prova. Ela observa, mede, correlaciona, detecta drift, aciona contraprova e entrega evidência ao `REALITY_JUDGE`.

```text
👑 SEGREDO/CHEFE
      │ intenção + autoridade
      ▼
☀️ SOL ────────────── coordena / reconcilia
      │
      ├──────────────► ☿ HERMES ── executa / preserva
      │
      └──────────────► 🛡️ GUARDIÃ DA CASA
                             │
                             ├─ observa
                             ├─ mede
                             ├─ correlaciona
                             ├─ detecta drift
                             ├─ aciona META_LUPA
                             ├─ emite receipt
                             └─ alerta
                                    │
                                    ▼
                              ⊛ META_LUPA
                                    │
                                    ▼
                              ⚖ REALITY_JUDGE
```

## Regra de ouro

> A Guardiã sente a Casa. Ela não governa a Casa.

```text
GUARDIA_DEFAULT_MODE=READ_ONLY
GUARDIA_IS_NOT_AUTHORITY=true
GUARDIA_IS_NOT_WRITER=true
GUARDIA_IS_NOT_FINAL_JUDGE=true
GUARDIA_SELF_APPROVAL=false
ACTION_IS_NOT_PROOF=true
UNKNOWN_IS_NOT_PASS=true
REALITY_IS_JUDGE=true
ONE_SYSTEM_ONLY=true
NO_NEW_BRAIN=true
```
