# TRES TEMPERATURAS — META LUPA

## Conceito

A MetaLupa opera em três temperaturas:

| Temperatura | Estado | Características |
|-------------|--------|-----------------|
| **QUENTE** | HOJE | Missão, evidência, pendência, próximo passo |
| **MORNA** | SEMANA | Padrões, continuidade, erros em maturação |
| **FRIA** | REGRAS | Conhecimento estável, testável, aprovado |

---

## Quando Aplicar

- **Fato**: evidência direta (hash, saída, código de saída).
- **Hipótese**: inferência plausível sem prova direta → marcar `NÃO_VERIFICADO`.
- **Candidato**: padrão observado mas ainda não validado.
- **Depreciado**: técnica rejeitada ou substituída.

---

## Aplicação na Sessão

Durante o inventário:

1. **Fato**: Hermes reporta `VERDICT=VALID` com hash.
2. **Hipótese**: SOL questiona se `NUL` é arquivo real.
3. **Candidato**: técnica UIA para ler tela.
4. **Depreciado**: PowerShell inline complexo.

---

## Gate de Verificação

Antes de declarar conclusão:

```
MAPAR
→ EVIDÊNCIA
→ CRENÇA
→ TESTE
→ DECISÃO
→ AUTOLUPA
→ CONSOLIDAÇÃO
```

---

## AutoLupa

Após qualquer resultado:

```
O que foi declarado?
Qual ação real ocorreu?
Qual rastro prova?
Qual evidência contrária foi procurada?
O mecanismo foi observado ou inferido?
Existe duplicata?
Existe perda de capacidade?
Existe segredo exposto?
Existe ação perigosa?
Existe falso verde?
Existe rollback?
O mesmo erro pode voltar?
```

Se o erro ainda pode voltar sem ser detectado:

```
MISSÃO AINDA NÃO ESTÁ CONSOLIDADA
```
