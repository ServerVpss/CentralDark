Escopo: CASA/Windows, VPS/Linux, gateway/router, backend, frontend, sessões, autorização, rate limit, sanitização de erros, circuit breaker, auditoria, Docker, banco privado/Supabase/Postgres, Painel Admin > Segurança, incidentes, backup/restore e testes negativos.

## Regra de integração

Este ZIP **não vira arquitetura paralela**. O agente deve `#ACORDAR !CALIBRAR`, medir o repo vivo, localizar o dono canônico de cada capacidade e fundir apenas o delta. Criar arquivo novo só quando a lacuna for comprovada.

Proibido: deploy, DNS, aplicar firewall remoto, SQL destrutivo em produção, secrets/.env/tokens/chaves, force-push, contra-ataque.

Postura: `PEACE=DEFAULT | HOUSE=PRIVATE | DEFENSE=ACTIVE | RETALIATION=NO | DEFAULT_ACCESS=DENY | SECRET_VISIBILITY=STATUS_ONLY | UNKNOWN=NOT_PASS`.
