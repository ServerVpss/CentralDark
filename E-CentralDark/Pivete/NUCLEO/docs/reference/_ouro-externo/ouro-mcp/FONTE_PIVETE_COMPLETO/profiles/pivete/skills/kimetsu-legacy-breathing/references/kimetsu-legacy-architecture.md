## Runtime Global

**CONCENTRAÇÃO TOTAL** — Kernel que mantém todas as Respirações funcionando.
Não compete com as Respirações; é o runtime que as executa.

### Ciclo Obrigatório (Concentração Total)

**Antes de agir:**
```
READ_INTENT()
MEASURE_STATE()
IDENTIFY_TARGET()
IDENTIFY_WRITER()
IDENTIFY_CONSTRAINTS()
SEPARATE_KNOWN_UNKNOWN()
```

**Depois de agir:**
```
MEASURE_AGAIN()
COMPARE_BEFORE_AFTER()
CLASSIFY_RESULT()
SELECT_NEXT_BREATH()
```

### Invariantes do Kernel
```
UNKNOWN != PASS
ACTION != PROOF
HISTORY != CURRENT_STATE
ASSUMPTION != FACT
```

## SOL — Meta-Orquestrador

**Função:** Observa o sistema inteiro, classifica o problema, roteia para a Respiração especializada.

**Ciclo:**
```
OBSERVE → CLASSIFY → ROUTE → EXECUTE SPECIALIST → COLLECT EVIDENCE → REASSESS
```

**Perguntas obrigatórias:**
- Qual é a intenção?
- Onde estamos?
- Qual é a ferida?
- Que tipo de problema é este?
- Qual Respiração possui maior ajuste?
- Qual o blast radius?

## LUA — Espelho Adversarial

**Derivação:** Paralela do SOL (não descendente).
**Função:** Tentar quebrar a conclusão antes do fechamento.

**Executar:**
```
TAKE_CURRENT_CONCLUSION
INVERT_ASSUMPTIONS
SEARCH_COUNTEREXAMPLE
TEST_FAILURE_PATH
TEST_BOUNDARIES
ATTEMPT_FALSIFICATION
```

**Regra:** Writer não julga sozinho a própria vitória.
