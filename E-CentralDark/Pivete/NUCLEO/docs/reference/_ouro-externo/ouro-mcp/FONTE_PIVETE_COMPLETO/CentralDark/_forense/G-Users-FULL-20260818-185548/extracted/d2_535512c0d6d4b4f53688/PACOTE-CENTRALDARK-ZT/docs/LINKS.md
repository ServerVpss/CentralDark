## Capacidade principal do browser-use

Permite que um agente de IA:
- Abra páginas
- Clique, digite, preencha formulários
- Extraia dados
- Execute tarefas web de forma autônoma

Uso no CentralDark: tornar visível o agente local trabalhando (browser controlado pelo agente + conversa entre agentes).
