# 🌈🏠 CENTRALDARK — GLOBAL EXECUTION LOOP

**Status proposto:** CANÔNICO GLOBAL  
**Escopo:** todos os modelos, agentes, chats, sessões, janelas, ferramentas e rotas materiais da Casa  
**Princípio:** `UMA CASA · UM LOOP · MUITOS MOTORES`  
**Autoridade final:** 👑 SEGREDO/CHEFE  
**Juiz:** ⚖️ REALIDADE OBSERVÁVEL  
**Regra de criação:** ♻️ `REUSE_BEFORE_CREATE`

---

## 1. Objetivo

Este contrato existe para impedir que cada modelo mantenha uma inteligência operacional própria.

```text
GPT / CLAUDE / GEMINI / CODEX / GROK / HERMES / FUTUROS MODELOS
                              ↓
                     🚪 PORTA GLOBAL
                              ↓
                🌐 UM OWNER OPERACIONAL
                              ↓
                 🧠🛠️👀 LOOP GLOBAL
```

Arquivos específicos de modelo podem existir apenas como **adaptadores finos de descoberta** quando a ferramenta exigir um filename próprio.

```text
ADAPTADOR ≠ OWNER
MODELO ≠ AUTORIDADE
MODELO ≠ VERDADE
MUITOS MOTORES ≠ MUITAS LEIS
```

A inteligência operacional deve morar **uma vez só**.

## 4. ReAct da Casa

### 🧠 THINK
Formular a menor próxima hipótese ou ação capaz de aumentar informação.

### 🛠️ ACT
Executar somente ação permitida pelo escopo e autoridade vigentes.

### 👀 OBSERVE
Ler o efeito real.  
Não inferir sucesso por intenção, log parcial ou palavra do modelo.

### 🔄 UPDATE_STATE
Atualizar a crença e o estado operacional com base no observado.

### 🧪 COUNTERPROVE
Tentar falsificar a própria conclusão no mesmo alvo.

### 🩹 REMEDY
Se a conclusão caiu e a correção está provada + autorizada, corrigir **nesta mesma execução**.

### 📏 REMEASURE
Medir novamente o alvo após a correção.

### ✅ FIXED POINT
Fechar apenas quando o alvo local sobrevive à nova medição e contraprova.

## 5. Regra central de erro

```text
💥 ERRO DESCOBERTO
→ 🧬 PROVAR CAUSA
→ 🧠 DERIVAR CORREÇÃO
→ ♻️ REUSAR OWNER/CAPACIDADE EXISTENTE
→ 🩹 CORRIGIR AGORA, SE AUTORIZADO
→ 🧪 CONTRAPROVAR
→ 📏 REMEDIR
→ 🔁 CONTINUAR SE SOBROU DELTA
→ ✅ FIXED_POINT_LOCAL
→ 🧾 DEIXAR RECIBO EXATO
```

### Regra

> **Erro descoberto não vira apenas relatório.**  
> Se causa, correção, autoridade e caminho material já estão provados, a correção continua na mesma execução.

Não é:

```text
DESCOBRIU
→ DOCUMENTOU
→ DEIXOU PARA A PRÓXIMA
```

É:

```text
DESCOBRIU
→ CORRIGIU
→ TESTOU
→ CONTRAPROVOU
→ REMEDIU
→ DEIXOU O PRÓXIMO COMEÇAR DO ESTADO CORRIGIDO
```

## 6. Aprendizado → capacidade

```text
ERRO + CAUSA + SOLUÇÃO REUTILIZÁVEL
→ REDUZIR CHANCE DE REPETIÇÃO
```

Antes de criar qualquer skill/comando/sistema:

```text
EXISTING_OWNER_FITS?
├─ SIM → ♻️ ABSORVER DELTA ÚNICO NO OWNER EXISTENTE
└─ NÃO
   ↓
   EXISTE SINAL REUTILIZÁVEL?
   ├─ repeated_across_sessions
   ├─ preventable_recurrent_error
   ├─ complex_multi_step
   └─ standardization_needed
       ↓
       SIM → validar UMA skill/comando canônico
       NÃO → procedimento local mínimo
```

Nunca criar V2/V3, segundo cérebro, segundo workflow ou segundo owner apenas porque mudou o modelo ou a janela.

```text
UNKNOWN != PASS

SKIPPED != PASS
CANCELLED != PASS

MERGED != MAIN_CONFIRMED
MAIN_CONFIRMED != FIXED_POINT
FIXED_POINT_LOCAL != MISSION_END
```

## 8. Política de mutação

### 👀 Percepção
Pode paralelizar.

### ✍️ Mutação
Deve serializar.

```text
PARALLELIZE_PERCEPTION=true
SERIALIZE_MUTATION=true
ONE_WRITER_PER_SCOPE=true
```

Antes de qualquer mutação:

```text
📌 CLASSIFICAR ALVO
→ 👑 VERIFICAR AUTORIDADE
→ 👤 LOCALIZAR OWNER
→ ✍️ LOCALIZAR WRITER
→ 🚪 LOCALIZAR CATRACA/GATE APLICÁVEL
→ 🧪 TENTAR CONTRAPROVA
→ 🔒 BLOQUEAR DIVERGÊNCIA
→ 🧬 PRESERVAR HISTÓRIA
→ 🛠️ MUTAR
```

Se uma rota não usa o gate global padrão, ela só pode ser tratada como exceção quando a exceção for:

- determinística;
- explícita;
- limitada em escopo;
- sem nova autoridade;
- sem owner concorrente;
- contraprova disponível;
- recibo observável.
