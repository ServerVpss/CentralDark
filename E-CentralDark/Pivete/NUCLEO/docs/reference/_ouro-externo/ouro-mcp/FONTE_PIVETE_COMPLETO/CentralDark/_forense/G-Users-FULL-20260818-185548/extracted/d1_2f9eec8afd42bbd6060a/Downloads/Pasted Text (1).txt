Contexto ≠ intenção.
Intenção ≠ autorização.
Autorização ≠ execução.

A cadeia não pode depender de:

como justificativa suficiente.
A regra é:

VALIDAÇÃO ANTERIOR ≠ CONFIANÇA AUTOMÁTICA

INVALID  → DENY

sem ação








Silêncio não é permissão.
Contexto não é autorização.

Probabilidade não é autorização.

Uma interpretação plausível não é uma especificação.

Não existe caminho autorizado até o recurso que contorne este gate.
Isso inclui procurar:
caminhos alternativos;
fallbacks;
exceções;
estados não tratados;
chamadas diretas;
confiança transitiva;
resultados previamente validados;
combinações de condições que pulem uma etapa.
Se existir uma rota que permita chegar ao resultado sem a validação obrigatória, a cadeia possui uma brecha.
