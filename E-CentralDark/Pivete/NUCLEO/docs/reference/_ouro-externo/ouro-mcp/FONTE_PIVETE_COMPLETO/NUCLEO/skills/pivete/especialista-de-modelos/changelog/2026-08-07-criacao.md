## Falha registrada (MetaLupa §16)
- **Subagentes caíram em 429** (Token Plan rate limit). Tive que executar
  extração inline (curl + python HTMLParser). Falso verde evitado — não
  declarei "ouro extraído" sem ter lido.
- **Subagentes não** devem ser reusados para esse tipo de fetch básico
  (HTTP simples, sem rate-limit). Usar somente para tasks que justifiquem
  isolamento de contexto.

## Princípios aplicados
- **5-classes:** toda página é classificada na fonte.
- **Sem paralelo:** página é `modelos/gpt-5.5.md`, não `modelos/gpt-5.5-v2.md`.
- **Anti-contaminação:** Class D/E ficam listadas no anexo, não promovidas.
- **Sem invenção:** "Padrões de uso (Pivete)" e "Como a Casa usa" começam
  vazios. Não fabrico comportamento.
