## 0. REGRA DE AUTORIA E PROVENIÊNCIA

A CentralDark não transforma organização feita por modelo em autoria da intenção humana.

Fluxo correto:

```text
SEGREDO/CHEFE OBSERVA / INTUI / DEFINE
→ MODELOS FORMALIZAM / CONTRAPÕEM / TESTAM
→ ESTADO REAL DESEMPATA
→ OURO SOBE
→ PROVENIÊNCIA É PRESERVADA
→ CAPACIDADE É ABSORVIDA NO DONO CANÔNICO
```

Nenhum modelo, agente, skill, documento histórico ou executor herda a autoridade humana.

```text
SEGREDO/CHEFE = HUMANO + AUTOR DA INTENÇÃO + AUTORIDADE FINAL
SOL = COORDENAÇÃO / SÍNTESE / CONTRAPROVA
PERFIL PIVETE = PERFIL OPERACIONAL
HERMES = EXECUTOR / CONTINUIDADE
MODELOS = MOTORES SUBSTITUÍVEIS
```

## 1. PROPÓSITO CENTRAL

O objetivo da CentralDark não é colecionar modelos, prompts, skills ou frameworks.

É transformar a capacidade do SEGREDO/CHEFE de:

- enxergar complexidade;
- localizar feridas;
- dilatar a ferida antes de tampá-la;
- extrair informação do erro;
- cruzar mentes, ferramentas, história e runtime;
- destruir hipóteses fracas;
- encontrar a causa geradora;
- preservar o que funciona;
- comprimir experiência;
- fundir ouro com ouro;
- reconstruir capacidade a partir de um núcleo cada vez menor;

em uma **capacidade operacional privada, persistente e recuperável**.

Formulação curta:

```text
VISÃO GRANDE
→ FERIDA
→ DILATAÇÃO CONTROLADA
→ INFORMAÇÃO NOVA
→ CONTRAPROVA
→ INVARIANTE CAUSAL
→ OURO
→ COMPRESSÃO
→ RECONSTRUÇÃO
→ CAPACIDADE PRESERVADA
```

## 2. MENOS É MAIS — SIGNIFICADO REAL

Menos É Mais não é minificação estética.

É:

```text
NENHUM BYTE SEM FUNÇÃO
NENHUMA REGRA SEM CONSUMIDOR
NENHUM MECANISMO SEM CAUSA
NENHUMA DUPLICAÇÃO SEM JUSTIFICATIVA
```

O alvo não é 64 linhas.

As "64 linhas" são apenas um teste de pressão.

O gate real:

```text
CAPACIDADE_DEPOIS >= CAPACIDADE_ANTES
COMPLEXIDADE_DEPOIS << COMPLEXIDADE_ANTES
```

Se 64 linhas preservarem tudo, ouro.

Se 12 linhas preservarem tudo, melhor.

Se 437 forem o mínimo verdadeiro, 437 vencem.

O objetivo final é o **RESÍDUO MÍNIMO IRREDUTÍVEL**:
remover mais um byte faria alguma capacidade material morrer.

Uma solução intermediária pode ser apenas uma pá melhor para continuar cavando.
