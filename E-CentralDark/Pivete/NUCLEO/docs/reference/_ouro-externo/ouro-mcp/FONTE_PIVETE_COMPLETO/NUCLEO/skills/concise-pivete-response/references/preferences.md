# Observed Preferences from Session

- Use plain text only; avoid markdown fences or backticks unless explicitly asked for code.
- Keep paragraphs short (1-2 sentences); separate ideas with blank lines.
- Lead with status emoji (✅ success, ⚠️ warning, ❌ error, ℹ️ info) followed by brief context.
- Do not add filler phrases like "Let me know if you need anything else" unless user asks for next steps.
- Provide full Windows paths in plain text (e.g., C:\Users\danda\...), no markdown links.
- Show exact commands to run; omit extra explanation unless user asks why.
- Maintain a direct, respectful, concise tone matching user's style (use "beleza", "cara", "ok" when appropriate).
- If uncertain, state what is unknown and ask for clarification rather than guessing.
