# Incident Playbook
`DETECT -> VALIDATE -> CONTAIN -> PRESERVE EVIDENCE -> RECOVER -> VERIFY -> LEARN -> HARDEN`.
Permitido: deny, throttle, revoke, drop na própria fronteira, quarantine, isolar workload, desabilitar consumer comprometido, rotacionar credencial por processo seguro, restaurar backup.
Proibido: hack back, DDoS, acesso a terceiro sem autorização, callback ofensivo, malware.
