# REALTIME-FLOW

```
Infra (GitHub|VPS|CF|Contabo|Casa)
  → OBSERVE (READ_ONLY)
  → Guard-* emite EVENT (envelope)
  → Bridge → Buzz channel
  → SOL / Reviewer / Auditor veem
  → Painel mapa vivo atualiza estado do nó
  → Se precisar execução: especificação + ZT + Hermes
  → RESULT event de volta ao canal
```

Nunca: mensagem Buzz → execução direta.
