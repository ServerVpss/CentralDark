# CentralDark Grok Adapter

Pacote mínimo. Não contém a CentralDark inteira e não cria segunda lei.

Conteúdo:
- `.grok/skills/centraldark/SKILL.md` — adaptador fino.
- `APLICAR-COM-GROK.txt` — instrução para o próprio Grok medir o repositório antes de instalar/reconciliar.

Uso:
1. entregue o ZIP ao Grok;
2. cole o conteúdo de `APLICAR-COM-GROK.txt`;
3. ele mede o repo e decide o encaixe real;
4. se já houver dono equivalente, evolui o existente em vez de duplicar.

Nenhum secret, deploy, VPS ou estado vivo do repositório está embutido neste pacote.
