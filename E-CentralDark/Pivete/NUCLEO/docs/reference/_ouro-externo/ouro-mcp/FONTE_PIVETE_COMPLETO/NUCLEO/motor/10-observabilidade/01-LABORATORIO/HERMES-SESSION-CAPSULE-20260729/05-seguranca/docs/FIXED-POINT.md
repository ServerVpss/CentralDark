# Fixed Point

```text
DESTINATION_REACHED
AND INVARIANTS_PRESERVED
AND BOUNDARY_PRESERVED
AND WRITER_CLEAN
AND CLAIM_PROVEN
AND COUNTERPROOF_SURVIVED
AND ROLLBACK_VALID_WHEN_APPLICABLE
AND NO_MATERIAL_UNKNOWN
AND NO_NEW_INFORMATION
→ FIXED_POINT
```

Caso contrário:

```text
LOCALIZE_RESIDUAL
→ EXISTING_OWNER
→ MINIMUM_DELTA
→ REMEASURE
→ COUNTERPROOF
```
