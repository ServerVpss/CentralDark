## O que este pacote faz

1. Preserva o marco arquitetural útil da sessão.
2. Separa estado vivo de relato histórico/local.
3. Consolida o padrão de cristalização de erro sem multiplicar arquiteturas.
4. Marca afirmações npm incorretas/fortes demais como CONTRADITADAS ou NÃO PROVADAS.
5. Entrega handoff para integração no Hermes sem criar segundo cérebro.
6. Inclui fonte original, handoff-mãe anterior, visuais, hashes, manifesto, prova e contraprova.
