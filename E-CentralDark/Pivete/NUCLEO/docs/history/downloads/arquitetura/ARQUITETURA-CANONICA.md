# ARQUITETURA CANÔNICA — FLUXO ÚNICO DA CASA

```text
SEGREDO/CHEFE
  intenção + autoridade final
        │
        ▼
ENTRADAS / SUPERFÍCIES / ADAPTERS
  chat • voz • imagem • arquivo • URL • browser • DevTools • Recorder
  WebMCP/MCP • Screenpipe(local se existir) • Notepad LocalState(local se existir)
  filesystem • Git/GitHub • logs/runtime • sensores candidatos
        │
        ▼
SOL — ONE CORE
  #ACORDAR → recuperar estado vivo
  !CALIBRAR → alinhar intenção/escopo/tools/prova
        │
        ▼
PERCEPÇÃO READ-ONLY EM PARALELO
  history • live repo • writers/owners • runtime/tools • continuity delta
        │
        ▼
ENVELOPE DE EVIDÊNCIA
  target • scope • event_time • observation_time • provenance • claim • evidence_ref • class
        │
        ▼
NORMALIZE → DEDUPE → CAUSALIDADE → CONTRAPROVA → !MULTIBUSSOLA → RENDEZVOUS
        │
        ├── sem delta material ───────────────► NO_CHANGE
        │
        ▼
MEMÓRIA / KNOWLEDGE COMPILER / GARIMPO
  RAW != CANONICAL • fonte=proveniência • só ouro provado sobe
        │
        ▼
DECISÃO
  menor capacidade suficiente • menor risco • maior ganho informacional
        │
        ▼
ORQUESTRAÇÃO ONE_CORE_MANY_ARMS
        │
        ▼
[se mutação] !EXECUÇÃO_REVERSÍVEL
        │
        ▼
ONE_WRITER_PER_SCOPE
        │
        ▼
PIVETE/HERMES → MODELO/TOOL/RUNTIME → EFEITO OBSERVÁVEL
        │
        ▼
[se houve ação] !REMEDIÇÃO T0→T1
        │
        ▼
REALITY JUDGE
        ├── FAIL/UNKNOWN → causa → menor correção → loop
        └── PASS → CRISTALIZAR OURO → RECEIPT → COCKPIT → RECUPERAÇÃO → FIXED_POINT
```

Browser, Recorder, Screenpipe, WebMCP, Notepad, longitude/latitude, rádio e Morse são fontes/adapters/sensores. Eles não alteram o pipeline nem criam outro cérebro. Cockpit é superfície, não inteligência. Modelo é motor, não SOL. ZIP é cache/entrega, não fonte da verdade.

## Build local ponta a ponta

`repo vivo → owners canônicos → portable-kernel existente → inventário Git completo → testes canônicos → builds locais existentes → T1 → receipt/cockpit`

O launcher não executa npm install, pull/fetch, deploy, push, reset hard, force push, limpeza de browser ou CCleaner.
