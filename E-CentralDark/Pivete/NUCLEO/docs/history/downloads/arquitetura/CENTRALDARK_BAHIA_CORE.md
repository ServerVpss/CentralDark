## Resumo

Visual de arquitetura operacional que liga Motor Hermes e Interface Visual: intenção → estado real → contraprova → núcleo → execução → evidência.

## Fluxo lógico

- **INTENCAO** — Percepção contínua
- **ESTADO_REAL** — Leitura em tempo real
- **CONTRAPROVA** — Testes e validações
- **NUCLEO** — Memória operacional
- **EXECUCAO** — Ações observáveis
- **EVIDENCIA** — Registro do que foi feito
- **INTERFACE** — Desktop, runtime, bot, Obsidian, dashboard
