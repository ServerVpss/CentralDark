# RASTRO CANÔNICO

## Intenção
Entregar UMA família autocontida sobre cognição animal + arquiteturas neurais/sistêmicas OpenAI,
sem artefatos necessários fora do pacote.

## Cadeia
INTENÇÃO
→ ESTADO PÚBLICO MEDIDO
→ SEPARAÇÃO HISTORY / LIVE_STATE
→ CATÁLOGO OPENAI
→ CATÁLOGO BIO-COGNITIVO
→ CONTRAPROVA
→ DENOMINADOR CROSS-AGENT
→ MANIFESTO
→ HASHES
→ VERIFICAÇÃO
→ ZIP ÚNICO

## Cadeados
- HISTORY != CURRENT_STATE
- BIOLOGICAL_INSPIRATION != OPENAI_BLUEPRINT
- AGENT_ARCHITECTURE != NEURAL_ARCHITECTURE
- UNKNOWN != PASS
- IMAGE != RUNTIME_PROOF
- REALITY = JUDGE

## Estado
O pacote não declara 100% global.
A topologia neural interna exata de GPT-5.6 permanece UNKNOWN_PUBLICLY.
O total mundial canônico de espécies com cognição registrada permanece UNKNOWN.

## Superfície de entrega
O ZIP é a única superfície de handoff.
Os arquivos internos são componentes da mesma família, não entregas concorrentes.
