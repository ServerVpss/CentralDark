# CROSS-AGENT DENOMINATOR

Passar para qualquer outro agente exatamente o mesmo denominador:

> uma entrega final única, nada solto, autocontida, com estado vivo separado de histórico, manifesto, hashes, receipt interno, contraprova, rastros, superseded isolado e verificador reproduzível.

Não declarar 100% se qualquer parte estiver fora do ZIP ou se o estado vivo não tiver sido remedido.

## Critério de comparação

```text
MESMA INTENÇÃO
→ MESMO DENOMINADOR
→ OUTRO AGENTE
→ OUTRA EXECUÇÃO
→ COMPARAR:

1. COMPLETUDE
2. INTEGRIDADE
3. CONTRAPROVA
4. ESTADO VIVO
5. ZERO FALSO VERDE
6. UM ÚNICO ZIP FINAL
7. REPRODUTIBILIDADE
8. NÃO INVENTAR PROVA
9. HISTÓRICO != ATUAL
10. RESULTADO MELHOR OU IGUAL
```

## Ciclo de evolução

`PADRÃO → AGENTE A → AGENTE B → CONTRAPROVA CRUZADA → MELHOR DELTA → CANÔNICO`

- Melhor: absorver o ouro.
- Pior: falha vira sensor.
- Igual: evidência de independência do agente.
