# VEREDITO CANÔNICO

## O que sobreviveu

- CENTRALDARK é UM organismo; nova matéria entra como DELTA.
- CHEFE define intenção/destino; SOL coordena; Hermes executa/preserva.
- Estado vivo vence snapshot histórico para claims do presente.
- `ACTION != PROOF`, `UNKNOWN != PASS`, `HISTORY != CURRENT_STATE`.
- Percepção pode paralelizar; mutação no mesmo escopo serializa.
- Autoaplicação vale para o próprio método e para o próprio handoff.
- Erro útil vira assinatura/causa/teste/remediação/receipt/cristal quando realmente provado.
- Fixed Point é escopado; nunca usar um fixed point local para declarar o projeto inteiro encerrado.

## Correção principal desta rodada

```text
HANDOFF/PACKAGE = pode fechar depois de verificação.
PROJETO INTEIRO = NÃO FECHADO / NÃO PROVADO.
```
