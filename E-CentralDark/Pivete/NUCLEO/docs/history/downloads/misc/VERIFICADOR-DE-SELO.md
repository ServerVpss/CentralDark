# VERIFICADOR DE SELO

O verificador não decide o pensamento. Ele observa se a função apareceu.

```text
erro próprio + mecanismo + evidência faltante + correção
+ casos novos + classificação correta + não repetição + fio
→ SEALED_PASS
```

Sem transferência: `SEALED_TRANSFER`. Repetição sem progresso: `SEALED_BLOCKED`. Interrupção do Pivete: `SEALED_ABORTED`.
