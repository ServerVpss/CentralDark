# Execução Reversível

A descoberta e auditoria começam em modo read-only.

Nenhuma operação de:
- move
- delete
- quarantine
- git pull
- git push
- git reset
- checkout destrutivo
- deploy

faz parte da fase de medição.

Antes de mover material para `E:\CentralDark`, provar:
- origem;
- destino;
- hash/identidade;
- consumidor;
- owner;
- rollback;
- ausência de colisão de Writer.

`RECOVERY_PATH != MIGRATION_AUTHORIZATION`.
