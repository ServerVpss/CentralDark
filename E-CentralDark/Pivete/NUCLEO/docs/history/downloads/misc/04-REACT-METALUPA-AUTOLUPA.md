# 04 — REACT + META LUPA + AUTOLUPA

```text
ReAct: ESTADO → AÇÃO → OBSERVAÇÃO → NOVO ESTADO
META LUPA: RESPOSTA → ORIGEM → FATO → INFERÊNCIA → LACUNA → EVIDÊNCIA
AUTOLUPA: CORREÇÃO → NOVO CASO → NOVA LUPA → NÃO REPETIÇÃO
```

ReAct conduz. A META LUPA revela o mecanismo do erro. A AUTOLUPA verifica se ele foi reconhecido em outra forma. O selo apenas registra a demonstração funcional.
