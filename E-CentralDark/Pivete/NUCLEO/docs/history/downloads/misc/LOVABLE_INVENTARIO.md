# Inventário Lovable

Gap histórico conhecido do pacote anterior.

## Regra de prova

`NENHUM_CAMINHO_ENCONTRADO` só pode ser emitido após varredura declarada do denominador aplicável.

Enquanto a varredura atual não for executada:

`LOVABLE_RUNTIME_STATUS=UNKNOWN`

Fontes a conferir em auditoria:
- Casa (`E:\CentralDark`)
- perfil do usuário
- AppData relevante
- Git roots
- workflows/configuração no repositório
- documentação/receipts históricos

Nenhuma desativação é autorizada por este arquivo.
