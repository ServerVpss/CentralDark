# CENTRALDARK — LACUNA FECHADA

## Título
**critério de saída, estado vivo e retorno somente com prova**

## Lacuna material
- `DESTINATION_LOCK` sem juiz final material gera retorno cedo demais.
- `SEARCH_ALL_MATERIAL_PATHS` sem `ESTADO_VIVO` procura rota em cima de suposição velha.
- `RETURN` somente quando resolvido é incompleto sem fronteira humana real.

## BOOT canônico corrigido
```text
CHEFE_INTENT → DESTINATION_LOCK → MEASURE_LIVE_STATE → SEARCH_ALL_MATERIAL_PATHS → RESOLVE_CANONICAL_OWNER → ACQUIRE_WRITER_IF_NEEDED → EXECUTE_MINIMAL_DELTA → COLLECT_EVIDENCE → COUNTERPROOF → REALITY_JUDGE → DESTINATION_PROVED ? RETURN : REMEDIATE_OR_ESCALATE_HUMAN_FRONTIER
```

## Versão comprimida
```text
INTENT → DESTINATION_LOCK → STATE_ALIVE → PATH_DISCOVERY → OWNER/WRITER_GUARD → EXECUTE → EVIDENCE → COUNTERPROOF → REALITY_JUDGE → RETURN_ONLY_IF_PROVED_OR_HUMAN_FRONTIER
```

## Fio da missão
```text
intenção → destino travado → estado vivo → descoberta automática dos caminhos → owner/writer correto → execução mínima necessária → prova → contraprova → realidade confirma → retorno somente quando provado ou quando houver fronteira humana real
```

## Cadeados
- `CHEFE DEFINE O DESTINO`
- `AÇÃO != PROVA`
- `REALITY = JUDGE`
- `REUSE_BEFORE_CREATE`
- `ONE_WRITER_PER_SCOPE`

## Retorno
A Casa só retorna quando o destino estiver provado pela realidade ou quando existir fronteira humana real comprovada.
