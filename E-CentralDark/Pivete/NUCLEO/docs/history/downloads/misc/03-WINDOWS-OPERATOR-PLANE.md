# SOL OPERATOR PLANE — WINDOWS

A aprendizagem só é operacional se o CHEFE conseguir enxergar e controlar.

## Home — Radar de Aprendizado

Mostrar sempre:

```text
HERMES           ONLINE|OFFLINE
RADAR            ON|OFF
CAPTURE           ON|OFF
LEARNING          ON|OFF
MODE              OFF|OBSERVE|LEARN|TEACH|EXTERNAL_RADAR|PRIVATE|REVIEW
SESSION_ID
SOURCE_CURRENT
QUEUE_PENDING
QUEUE_PROGRESS
LAST_CRYSTALLIZATION
BLOCKERS
```

## Botões obrigatórios

```text
[LIGAR RADAR]
[PAUSAR]
[RETOMAR]
[MODO ENSINAR]
[MODO PRIVADO]
[REVISAR]
[ENCERRAR SESSÃO]
[ABRIR NUCLEO]
[ABRIR OBSIDIAN]
[PARAR TUDO]
```

`PARAR TUDO`:
- impede nova captura;
- impede novas escritas;
- pausa filas;
- preserva checkpoint;
- não apaga evidência.

## Aba “Aprendeu hoje”

```text
RELATES_TO
VALIDATION

```

Ações:
`VER FONTE`, `VER EVIDÊNCIA`, `CORRIGIR`, `DESCARTAR`, `FIXAR`, `ESQUECER CANDIDATO`.

## Aba “Sessão”

Não mostrar `% de inteligência`.

Mostrar:
- capturados;
- processados;
- validados;
- cristalizados;
- rejeitados;
- ruído;
- pendentes;
- erro/unknown;
- progresso da fila.

## Indicador de captura

Quando microfone/transcrição estiver ativo, deve haver indicador persistente visível.

`HIDDEN_CAPTURE=false`
