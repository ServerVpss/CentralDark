# PRIMEIRO MARCO MENSURÁVEL

> CHEFE escreve uma intenção curta; sem indicar agente, arquivo, branch ou ferramenta, a CentralDark recupera o estado, descobre trabalhos independentes, distribui braços disponíveis, impede colisões, resolve o que está autorizado, prova e retorna somente com resultado/resíduo.

## Teste de aceitação

Entrada:
- uma intenção curta;
- nenhuma indicação manual de agente/arquivo/branch/tool.

O sistema deve provar:
1. estado vivo recuperado;
2. owner/capacidade existentes encontrados antes de criar;
3. trabalhos independentes separados;
4. percepções paralelas sem Writers concorrentes;
5. uma mutação por escopo;
6. prova no mesmo alvo;
7. contraprova aplicada;
8. remediação automática se houver resíduo;
9. retorno apenas em fixed point local ou fronteira humana real;
10. receipt reproduzível.
