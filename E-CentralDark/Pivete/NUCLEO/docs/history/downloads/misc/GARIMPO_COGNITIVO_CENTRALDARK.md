# Garimpo Cognitivo CentralDark

## Natureza

Pacote reconciliado retroativamente para cumprir o padrão visual canônico da CentralDark:

`IMAGE → MARKDOWN → MERMAID → ZIP`

Este documento descreve **o que o visual representa**. Ele não promove texto desenhado na imagem a estado de runtime.

> IMAGE != DOCUMENTATION  
> DOCUMENTATION != DIAGRAM  
> VISUAL_CLAIM != RUNTIME_PROOF  
> REALITY = JUDGE

## Resumo

Pipeline visual de captura, processamento, destilação e cristalização: material bruto entra, o ouro útil sobrevive e retorna à Casa.

## Fluxo lógico

- **CAPTURA** — Conversas, arquivos, prints, logs, fontes
- **PROCESSAMENTO** — Extrair, normalizar, ordenar, deduplicar
- **CONTRAPROVA** — Separar fato, claim, inferência e unknown
- **DESTILACAO** — Comprimir sem perder capacidade
- **CRISTAL** — Conhecimento reutilizável
- **KANBAN** — Ação elegível
- **MEMORIA** — Continuidade
