# OWNERSHIP MAP

| Plano | Owner/papel | Regra |
|---|---|---|
| intenção/autoridade | SEGREDO/CHEFE | humano e autoridade final |
| coordenação | SOL | não vira segunda autoridade |
| percepção | readers/adapters | read-only por padrão |
| harvester | session-intelligence-harvester | uma colheita, muitas fontes |
| dedupe/cristal | knowledge-compiler | muitos inputs, uma rota operacional |
| contraprova | MetaLupa/Judge | sem voto de modelo |
| mutação | Writer único | uma caneta por escopo |
| execução | PIVETE/HERMES | preservação + continuidade |
| prova | Reality Judge / proof owner | mesma target/scope |
| observabilidade | logs/receipts/grafo/painel | projeção != verdade |
| interface | cockpit web/desktop | superfície != inteligência |

## Anti-duplicação

Se duas peças representam a mesma função:
1. medir;
2. escolher owner canônico;
3. absorver delta;
4. remover apenas duplicação provada e autorizada;
5. manter compatibilidade quando necessária.
