# Cartão Operacional CentralDark — 5 Lentes

## Natureza

Pacote reconciliado retroativamente para cumprir o padrão visual canônico da CentralDark:

`IMAGE → MARKDOWN → MERMAID → ZIP`

Este documento descreve **o que o visual representa**. Ele não promove texto desenhado na imagem a estado de runtime.

> IMAGE != DOCUMENTATION  
> DOCUMENTATION != DIAGRAM  
> VISUAL_CLAIM != RUNTIME_PROOF  
> REALITY = JUDGE

## Resumo

Cartão do método de investigação em cinco lentes: físico → temporal → causal → contraprova → prova.

## Fluxo lógico

- **FISICO** — Onde existe?
- **TEMPORAL** — Quando mudou?
- **CAUSAL** — O que mudou junto?
- **CONTRAPROVA** — Qual hipótese elimina concorrentes?
- **PROVA** — Qual evidência encerra a conclusão?
