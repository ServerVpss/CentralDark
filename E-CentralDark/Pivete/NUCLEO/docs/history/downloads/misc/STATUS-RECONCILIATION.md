# STATUS RECONCILIATION

VERMELHO != ERRO ETERNO
AMARELO != PENDÊNCIA ETERNA
VERDE != VERDADE ETERNA

STATUS_KEY = source + scope + artifact + HEAD/SHA + timestamp + cause_signature

Evidência nova do mesmo denominador substitui snapshot velho. Mudança de HEAD invalida só claims dependentes. Repetição pela mesma causa vira cluster causal. Foto é evidência observacional, não prova de runtime sozinha.
