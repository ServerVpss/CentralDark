# CENTRALDARK — ONE FLOW PLUG KIT

Status: pacote de integração / handoff, **não** um segundo sistema.

## Intenção canônica

SEGREDO/CHEFE define **O QUE**.  
A Casa descobre **COMO** usando capacidades existentes.  
SOL coordena e reconcilia.  
PIVETE/HERMES executa, preserva e mantém continuidade.  
MODELO é motor substituível.  
REALITY = JUDGE.

## Regra de instalação

Este pacote **não deve ser copiado cegamente para o repositório**.

Fluxo correto:

1. `#ACORDAR`
2. medir branch/HEAD/PR/runtime;
3. reconciliar owners existentes;
4. reaproveitar antes de criar;
5. aplicar somente delta necessário;
6. um Writer por escopo;
7. testar no mesmo alvo;
8. Reality Judge;
9. cristalizar apenas ouro reutilizável.
