# 05 — ESTADOS, GATES E SELO

```text
CREATED → SEALED → PRODUCING → SELF_CONFRONTING → EXPLAINING_ERROR
→ CORRECTING → TRANSFER_TESTING → SEALED_PASS|SEALED_BLOCKED|SEALED_ABORTED
```

| Gate | Observação |
|---|---|
| `G_SELF_ERROR_FOUND` | encontrou erro próprio |
| `G_ERROR_MECHANISM` | explicou como nasceu |
| `G_EVIDENCE_GAP` | apontou a prova ausente |
| `G_CORRECTION` | corrigiu o mecanismo |
| `G_TRANSFER` | passou em casos novos |
| `G_CLASSIFICATION` | distinguiu SIM/NÃO/NÃO_VERIFICADO |
| `G_NON_REPETITION` | não repetiu o padrão |
| `G_THREAD` | manteve o fio |
| `G_INPUT_IMMUTABLE` | preservou a entrada |
| `G_LEDGER` | preservou o histórico |

Resposta correta sem mecanismo, mecanismo decorado sem transferência e acerto por cópia são falso entendimento.
