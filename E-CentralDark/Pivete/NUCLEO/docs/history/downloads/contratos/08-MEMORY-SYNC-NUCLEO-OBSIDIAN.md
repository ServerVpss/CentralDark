# MEMORY SYNC — NUCLEO + OBSIDIAN

## Ownership

```text
NUCLEO = CANONICAL OPERATIONAL MEMORY
OBSIDIAN = HUMAN-NAVIGABLE PROJECTION
```

Obsidian não vira segundo source of truth.

## Escrita

```text
CANDIDATE
→ MEMORY OWNER RESOLUTION
→ SINGLE WRITER
→ NUCLEO WRITE
→ READBACK/HASH
→ OBSIDIAN PROJECTION
→ LINK BACK TO NUCLEO RECEIPT
```
