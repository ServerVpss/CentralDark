# Máquina de Estados Epistêmica

```text
GREEN   = PROVEN
RED     = FAILED / BLOCKED
BLACK   = UNKNOWN / NOT_PROVEN
LOCKED  = QUARANTINE / HUMAN_LOCK
WORKING = FORJA / trabalho em curso
YELLOW  = FORBIDDEN AS PASS SEMANTICS
```

```text
UNKNOWN → MEASURE → TEST → OBSERVE_REALITY → PROVEN | FAILED | NOT_PROVEN

FAILED
→ CAUSE
→ EXISTING_OWNER
→ MINIMAL_DELTA
→ RETEST
→ COUNTERPROOF
→ REALITY_JUDGE

PROVEN
→ RECEIPT
→ HEAD/SHA/CHECKSUM
→ LEARNING
→ NEXT_CURSOR

STATE_CHANGED
→ PREVIOUS_RECEIPT = HISTORY
→ REMEASURE
```

Invariantes:
`ACTION != PROOF`
`HISTORY != CURRENT_STATE`
`SPEC != IMPLEMENTATION`
`SCREENSHOT != LIVE_STATE`
`UNKNOWN != PASS`
