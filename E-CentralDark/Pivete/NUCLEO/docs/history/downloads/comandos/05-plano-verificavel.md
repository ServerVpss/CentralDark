# 🎯 DESAFIO — Fix mínimo verificável

Fix precisa ter:
1. **Diff exato** (arquivo + linhas + código antes/depois)
2. **Baseline medido** (número absoluto atual)
3. **Meta numérica** (não "melhora bastante" — "381ms → ≤180ms")
4. **Método de verificação** (comando/script que qualquer um roda pra confirmar)
5. **Risco de regressão** (o que pode quebrar + como detectar)

Sem os 5, não é staff — é opinião.
