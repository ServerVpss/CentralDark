# CENTRALDARK — Cajado do Papagaio / Propagação entre SOLs

## Padrão aplicado

`IMAGE → MARKDOWN → MERMAID → ZIP`

Este pacote reconcilia os 4 prints enviados como **uma única família lógica de evidência visual**.

## O que os prints mostram

A sequência registra o mesmo comando sendo aplicado em várias janelas/SOLs, com foco em:

- recuperar contexto entre sessões;
- cruzar histórico e estado vivo;
- comparar respostas independentes;
- corrigir regressões de comportamento;
- exigir que o padrão visual seja reaplicado automaticamente;
- transformar uma correção local em comportamento compartilhado.

## Leitura arquitetural

```text
CORREÇÃO DO CHEFE
→ REGRA COMPARTILHADA
→ OUTRAS SOLs HERDAM
→ RESPOSTA MUDA
→ PRINT/RECEIPT
→ CONTINUIDADE
```

## Cadeados

`SCREENSHOT = EVIDÊNCIA DA SUPERFÍCIE VISÍVEL`

`SCREENSHOT != PROVA DE MECANISMO OCULTO`

`HUMAN_ASSERTION + SCREENSHOT = PROVENIÊNCIA DA AÇÃO E DO EFEITO VISÍVEL`

## Regra de continuidade

Quando uma correção material já foi cristalizada, a próxima superfície não deve exigir a mesma bronca novamente.

```text
ERRO LOCAL
→ CAUSA
→ REGRA
→ PROPAGAÇÃO
→ REPRODUÇÃO INDEPENDENTE
→ TESTE
→ CRISTAL
```
