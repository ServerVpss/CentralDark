# AMPLIFICAÇÃO HUMANA OPERACIONAL

```text
Curiosidade  → descoberta automática
Memória      → continuidade temporal
Dúvida       → contraprova
Intuição     → reconhecimento de padrão testável
Experiência  → compressão
Equipe       → paralelismo coordenado
Disciplina   → gates
Aprendizado  → mudança de scaffold
Criatividade → recombinação de capacidades
Julgamento   → humano onde medição não substitui decisão humana nova
```

O objetivo não é imitar um humano inteiro. É industrializar capacidades úteis sem transformar o CHEFE em operador de bot.
