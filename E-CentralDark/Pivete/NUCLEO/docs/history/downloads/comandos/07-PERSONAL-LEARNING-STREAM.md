# PERSONAL LEARNING STREAM — APRENDIZADO EXPLÍCITO COM O CHEFE

Não é vigilância da vida.

É uma sessão operacional iniciada e encerrada pelo humano.

## Comandos conceituais

```text
START TEACH
START STUDY
START WORK
START LISTEN
PAUSE
RESUME
PRIVATE
STOP
REVIEW
```

## Fontes possíveis por sessão

- microfone explicitamente autorizado;
- transcrição/legenda local;
- URL de vídeo/podcast selecionada;
- arquivo selecionado;
- notas/texto;
- pasta allowlisted;
- conteúdo enviado ao Hermes.

## Não permitido por padrão

- webcam contínua;
- captura oculta;
- leitura de mensagens privadas não selecionadas;
- senha/token;
- gravação ambiental invisível;
- “memorizar tudo”.

## Pipeline

```text
SESSION START
→ SCOPE RECEIPT
→ CAPTURE
→ CHUNK
→ TRANSCRIBE/NORMALIZE
→ DEDUPE
→ CLASSIFY
→ EXTRACT CANDIDATES
→ FORJA
→ SESSION SUMMARY
→ HUMAN REVIEW WHEN MATERIAL
→ CRYSTALLIZE
→ SESSION STOP
```

## O que não deve inferir como fato humano

Saúde, identidade sensível, crenças íntimas, intenção de vida, segredo, senha ou dado privado não devem ser inferidos/cristalizados a partir de exposição casual.
