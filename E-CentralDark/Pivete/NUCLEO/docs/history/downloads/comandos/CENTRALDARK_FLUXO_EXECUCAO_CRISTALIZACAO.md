# CENTRALDARK — DA EXECUÇÃO À CRISTALIZAÇÃO

## Ideia central
Menos linhas não é o objetivo. O objetivo é preservar ou aumentar capacidade enquanto se reduz a superfície exposta, repetição e atrito operacional.

## Fluxo
1. Execução real no terminal.
2. Superfície original (~62 linhas).
3. Compressão (~60 linhas).
4. Cristalização em 51 linhas.
5. Reuso: a skill curta atua como chave de ignição de uma infraestrutura maior.

## Princípio
```text
LOC != POWER
SKILL != WHOLE_SYSTEM
SKILL = COMPRESSED_CONTROL_SURFACE
FOR A MUCH_LARGER_CAPABILITY_GRAPH
```

## Gate
```text
CAPACIDADE_DEPOIS >= CAPACIDADE_ANTES
COMPLEXIDADE_EXPOSTA_DEPOIS << COMPLEXIDADE_EXPOSTA_ANTES
```

## Metáfora operacional
```text
51 LINHAS
→ CHAVE DE IGNIÇÃO
→ OWNERS + MEMÓRIA + SKILLS + TOOLS
→ MODELOS / EXECUTORES
→ TESTES / RUNTIME / RECEIPTS
→ CAPACIDADE REAL
```
