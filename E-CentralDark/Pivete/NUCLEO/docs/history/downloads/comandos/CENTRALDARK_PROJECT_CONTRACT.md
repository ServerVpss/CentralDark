# CENTRALDARK — CONTRATO DE PROJETO RECONCILIADO

## Autoridade
SEGREDO/CHEFE define O QUE e o DESTINO. SOL coordena/reconcilia. HERMES/PIVETE executa, preserva e mantém continuidade. Modelos/tools são meios substituíveis. REALIDADE julga claims.

Experiência → compressão.

Julgamento → humano apenas onde decisão genuinamente humana permanece necessária.

## Primeiro marco mensurável
CHEFE escreve uma intenção curta; sem indicar agente, arquivo, branch ou ferramenta, a CentralDark recupera o estado, descobre trabalhos independentes, distribui braços disponíveis, impede colisões, resolve o autorizado, prova e volta apenas com resultado/resíduo.
