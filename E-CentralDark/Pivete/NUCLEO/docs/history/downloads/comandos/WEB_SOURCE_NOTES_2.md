
# Notas das fontes

- NIST SSDF: framework de práticas de desenvolvimento seguro e prevenção de recorrência.
- NIST ZTA: zero trust remove confiança implícita; CentralDark usa isso apenas como analogia para confiança epistemológica.
- NIST AI RMF: Govern/Map/Measure/Manage são funções de gestão de risco, não um workflow sequencial obrigatório.
- SLSA 1.2: especificação aprovada com Build e Source tracks; é referência especializada de provenance e supply chain.
- OWASP Agentic 2026: framework peer-reviewed de riscos de agentes.
- OWASP SAMM: cinco funções de maturidade de software security.
- Google SRE: canary/error-budget são práticas de reliability, não equivalentes a PAPAGAIO_OFF.
- GitHub Rulesets: enforcement do host; não substitui governança semântica.
- IPP é **Internet-Draft / work in progress**, não padrão final do IETF.

Nenhuma fonte externa é usada para reivindicar autoria da CentralDark.
