# 06 — INTEGRAÇÃO CENTRALDARK, HERMES E BOLT

```text
PIVETE → Hermes Casa → missão → caixa → autoconfronto → casos novos
→ evidência → META LUPA → Git/PR → Pivete decide uso externo
```

Hermes transporta contexto, sessão, ferramentas e resultados. A caixa executa o ciclo do mesmo agente. O Bolt fornece problemas e casos de transferência reais. Git registra a evolução. Nenhuma dessas camadas substitui o entendimento do agente.

## Bolt

```text
erro real → resposta/patch → autoconfronto → mecanismo → correção
→ caso equivalente em outro módulo → não repetição → PR
```

A caixa não faz merge ou deploy por conta própria.
