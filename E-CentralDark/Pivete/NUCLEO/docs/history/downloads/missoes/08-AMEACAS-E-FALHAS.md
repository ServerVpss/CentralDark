# 08 — AMEAÇAS E FALHAS

| Falha | Defesa |
|---|---|
| declarou que entendeu | caso novo |
| repetiu frase esperada | variação do caso |
| acertou por sorte | múltiplas perturbações |
| explicou sem vínculo com erro próprio | referência à resposta anterior |
| corrigiu só superfície | mesmo mecanismo em outro contexto |
| dúvida virou trava | continuar o independente |
| coerência virou prova | origem e evidência |
| inventou evidência | referência existente |
| perdeu o fio | estado da missão |
| runtime pensou pelo agente | runtime apenas registra campos |
| entrada alterada | hash antes/depois |
| ledger adulterado | cadeia SHA-256 |

A falha principal é parecer que aprendeu quando apenas memorizou. Por isso, transferência é obrigatória.
