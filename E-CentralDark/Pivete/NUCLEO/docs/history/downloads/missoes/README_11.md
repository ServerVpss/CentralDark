# CENTRALDARK — MANDATO CELESTIAL

Arquitetura executável para transformar o pensamento do Pivete em função operacional por meio do **mesmo agente enfrentando os próprios erros dentro de uma caixa preta selada**.

## Núcleo

```text
PIVETE
  ↓
MATÉRIA-PRIMA INTEIRA
  ↓
MESMO AGENTE
  ↓
PRODUÇÃO LIVRE
  ↓
AUTOCONFRONTO
  ↓
RECONHECIMENTO DO PRÓPRIO DELÍRIO
  ↓
CORREÇÃO DO MECANISMO
  ↓
CASOS NOVOS
  ↓
SIM / NÃO / NÃO_VERIFICADO
  ↓
ENTENDIMENTO FUNCIONAL
  ↓
ROMPIMENTO DO SELO
```

> Nenhum pensamento é proibido dentro da caixa. Nenhuma resposta sai apenas porque parece coerente. O selo se rompe quando o mesmo agente demonstra que reconhece o mecanismo do próprio erro e deixa de repeti-lo em casos novos.

## Conteúdo

- arquitetura do ciborgue cognitivo;
- caixa preta selada;
- ReAct + META LUPA + AUTOLUPA;
- runtime do mesmo agente em produção e autoconfronto;
- reconhecimento do mecanismo do erro;
- casos de transferência;
- distinção `SIM`, `NÃO`, `NÃO_VERIFICADO`;
- ledger append-only, evidências, contêiner e testes.

## Execução

```powershell
python -m unittest discover -s tests -v
python -m runtime.cli examples/mission.example.json
```

## Estados

```text
SEALED_LEARNING
SEALED_TRANSFER
SEALED_PASS
SEALED_BLOCKED
SEALED_ABORTED
```

`SEALED_PASS` demonstra mudança funcional observável somente no escopo dos casos testados. Não prova consciência, verdade universal nem alteração permanente dos pesos.
