⌨️ Comandos prontos pra copiar

Windows (PowerShell), só conferir:

.\atualizar.ps1

Windows, aplicar de verdade:

.\atualizar.ps1 -Aplicar

Pasta veio de ZIP? clona ao lado sem apagar nada:

.\atualizar.ps1 -Aplicar -Clonar

Linux / VPS:

chmod +x atualizar.sh && ./atualizar.sh --aplicar

Ligar os hooks locais (trava antes do commit):

git config core.hooksPath .githooks
