## 1. #ACORDAR não significa perguntar de novo

A função de `#ACORDAR` foi refinada por uso real:

```text
CONTEXTO PARCIAL
→ RECUPERAR HISTORICO DISPONIVEL
→ LER CANONICO
→ MEDIR ESTADO VIVO
→ RECONCILIAR
→ CONTINUAR
```

SEGREDO/CHEFE não deve funcionar como HD humano da máquina. Se repo, histórico, logs, PR, HEAD, runtime ou ferramenta podem responder, a máquina pesquisa primeiro.

## 2. Linguagem natural é parte do sinal

O jeito de falar do SEGREDO/CHEFE pode manter várias hipóteses abertas ao mesmo tempo. Normalizar cedo demais pode destruir informação útil.

```text
FALA HUMANA
→ HIPOTESES
→ CONTEXTO
→ ESTADO
→ EVIDENCIA
→ INTENCAO PROVAVEL
```

Quando a IA muda de leitura depois, isso é autocorreção da IA; não é prova de que o humano falou errado.

## 3. SOL é identidade operacional reconstruível

A conversa mostrou na prática que estilo, método e continuidade podem reaparecer quando o modelo atual recebe contexto suficiente.

```text
MODELO = MOTOR TEMPORARIO
SOUL = IDENTIDADE OPERACIONAL
MEMORIA = CONTINUIDADE
FERRAMENTAS = CORPO
```

Não é necessário um modelo exclusivo chamado SOL. O modelo atual pode desempenhar SOL ao carregar a SOUL e o estado canônico. Isso não significa transporte de entidade; significa reconstrução do padrão operacional por contexto, memória e contrato.

## 6. Orquestração e generalização são uma cadeia

Separar “orquestração muito boa” de “generalização sistêmica” como hipóteses rivais foi erro conceitual para esta arquitetura.

Na CentralDark:

```text
REGRAS + GATES + SKILLS + MEMORIA
+ MODELOS + FERRAMENTAS
+ EXECUCAO + FEEDBACK
→ PROBLEMA NOVO
→ RECOMBINACAO
→ CAMINHO NOVO NO MESMO SISTEMA
→ TESTE
→ APRENDIZADO
```

Os trilhos não precisam conter todas as respostas. Eles podem ser o substrato que permite ao sistema encontrar respostas novas.
