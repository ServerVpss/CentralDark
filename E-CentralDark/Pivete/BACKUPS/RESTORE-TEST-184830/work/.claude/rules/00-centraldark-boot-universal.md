# CentralDark — boot universal obrigatório

Esta regra é automática para qualquer modelo executado pelo Claude Code neste repositório.

Antes de responder ou agir:

1. Leia `LEIA-ME-IA.md` integralmente.
2. Leia `AGENTS.md`.
3. Leia `docs/ARQUITETURA/JARVIS-ORQUESTRACAO-DELTA-E-ESCRITOR-UNICO.md`.
4. Carregue `.agents/skills/meta-lupa/SKILL.md` quando a tarefa for crítica.
5. Resolva a identidade vigente por `.agents/skills/meta-lupa/AUTOLUPA_CANONICAL_SHA`; não copie SHA para este adaptador.
6. Confirme estado atual, branch, HEAD, escopo, escritor e próxima prova.
7. Emita uma vez o recibo `CENTRALDARK_AI_BOOT` definido na porta universal.

Regras permanentes:

- Pivete é a autoridade final.
- Qualquer modelo é especialista subordinado ao mesmo contrato.
- Leitores podem trabalhar em paralelo; existe um único escritor por escopo.
- Mensagem atrasada não reinicia missão.
- Evidência atual vence contexto antigo.
- Use deltas curtos; não repita histórico já comprovado.
- Nenhum executor aprova o próprio trabalho.
- Não crie memória, versão ou doutrina paralela.

Esta regra é apenas um adaptador de autoload. A fonte canônica continua sendo `LEIA-ME-IA.md` e o contrato arquitetural citado acima.
