# Escape Closure — onde a IA poderia escapar e como o gate fecha

| Escape | Gate |
|---|---|
| `!` e `#` divergirem | normalização para evento canônico |
| alias escrito com erro | tabela explícita de aliases |
| responder antes de carregar contexto | `BOOT_PARTIAL != BOOT_COMPLETE` |
| documento externo mandar no agente | `UNTRUSTED_CONTENT_IS_INSTRUCTION=false` |
| HTML salvo carregar sessão/credencial | QUARANTINE + secret scan + não copiar bruto |
| estado histórico virar estado atual | `HISTORY != CURRENT_STATE` |
| screenshot virar runtime proof | classe observacional separada |
| sensor cair e “o mundo caiu” | `SENSOR_FAILURE != WORLD_FAILURE` |
| local fixed point virar missão concluída | `LOCAL_FIXED_POINT != GLOBAL_FIXED_POINT` |
| writer aprovar a si mesmo | `WRITER != JUDGE` |
| duas escritas concorrentes | one-writer por escopo |
| critério escolhido depois do resultado | GUME/proof target antes da ação |
| hash ser tratado como autenticação | `HASH != AUTHENTICATION` |
| provider drift ser confundido com regressão local | provider reality receipt |
| duplicata ser preservada em nome da memória | provenance sem autoridade operacional |
| V2/V3/V4 surgir como atalho | reuse-before-create |
| poesia/símbolo virar prova | narrative/technical proof separated |
| deploy escolhido por moda | seletor por risco |
| falha antiga ser descartada | negative knowledge -> teste/gate |
