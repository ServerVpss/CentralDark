# GitHub Profile — Continuous README Contract

## Objetivo
O README de perfil mostra estado, direção e projetos sem declarar a CentralDark como “finalizada”.

## Estrutura recomendada

### 👑 CentralDark
Sistema em evolução contínua. Estado observado, não promessa estática.

### 🧭 Foco atual
- arquitetura viva
- automação verificável
- documentação rastreável
- agentes substituíveis / missão contínua

### 🟢 Estado
Use estado medido com data/revisão. Evite badge que declare “100% pronto” sem denominador.

### 🧠 Arquitetura
Mapa curto: entrada → measure → reconcile → owner → test → counterproof → receipt.

### 📦 Projetos em destaque
Somente projetos atuais ou historicamente relevantes, com rótulo `ATIVO`, `EXPERIMENTAL`, `HISTÓRICO` ou `ARQUIVADO`.

### 📚 Documentação
Links diretos para owners vivos e documentação principal.

### 🔁 Evolução contínua
Nunca usar “projeto encerrado/finalizado” como estado global da CentralDark. Uma entrega pode estar concluída; a arquitetura continua evoluindo.

## Regra de limpeza
- sem mural de badges redundantes
- sem plugins visuais não verificáveis
- sem segredos
- sem status stale
- emoji = semântica, não decoração
