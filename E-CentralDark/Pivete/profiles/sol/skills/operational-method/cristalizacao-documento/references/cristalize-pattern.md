# Cristalize Consolidado — Padrão de arquivo

Referência de sessão: criação de `cristalize.html` consolidado no workspace (`E:\CentralDark\workspace`).

## Quando usar
Quando precisar de arquivo físico de consolidação/prova com:
- Cabeçalho resumido (ex: PERGAMINHO II/III)
- Pontos críticos (tabela com status)
- Evidência de arquivo local
- Status parcial ZIP
- Notas de PR/pendência

## Estrutura canônica
1. Cabeçalho (badge + título + resumo)
2. Resumo fonte (cards ou seções)
3. 5 pontos críticos (tabela: #, ponto, prova, status)
4. Evidência local (caminho físico + nota)
5. Status ZIP (`pre` + alerta se PARCIAL)
6. Nota PR / pendência (card + próximo passo)

## Regra de status
Nunca declare ciclo completo sem ZIP completo + AutoLupa + validação final. Se arquivo físico não existir no workspace, evidência NÃO provada.
