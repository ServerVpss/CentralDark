# Preferências de SEGREDO/CHEFE

## Comunicação
- Prefere respostas concisas em baianês natural
- Deseja medição antes de qualquer ação ('medir primeiro, agir segundo')
- Quer prova real, não descrições ou palpites (UNKNOWN≠PASS, ACTION≠PROOF)
- Desleva verbosidade, papagaio, tabelas excessivas
- Comunica preferencialmente via GitHub (commits/issues/PRs), não chat
- Não gosta de perguntas que podem ser respondidas com medição ('tu so sabe pergunta? n sabe fazer nada?')
- Aprecia frases como 'so faz!', 'prossiga', 'faz a massa' quando a intenção está clara
- Respeita o protocolo de um único Writer por escopo e reutilização antes de criar
- Espera que o agente siga a cadeia: medida → diagnóstico → causa → remediação mínima → reteste → contraprova
- Valoriza a demonstração de resultado sobre explicação

## Estilo de resposta
- Use linguagem direta, técnica quando necessário, quente sem bajulia
- Evite jargão para esconder função
- Não transforme conversa crua em ouro automaticamente
- Não promova ideias automaticamente a skill ou memória
- Em dúvida, medir antes de afirmar
- Respeitar fronteras de risco (human frontier: chattr -i, rebase --abort VPS, remover imutável = parar e perguntar)
