# Normalização Semântica — Conceitos Operacionais CentralDark

Esta normalização define a família de conceitos e o fluxo canônico para operações no CentralDark.

## Família Reconhecida
- META_LUPA
- FALSE_GREEN
- ACORDAR_CALIBRAR
- MULTIBUSSOLA
- FIXED_POINT
- GRAPH_COGNITIVE
- TIC_TAC

## Fluxo Operacional Obrigatório
1. READ_ONLY primeiro
2. Mapa cognitivo
3. GraphRAG
4. SELF_HEALING_FAILURE_LOOP
5. CONTRAPROVA
6. REALITY_JUDGE
7. FIXED_POINT | REMEDIAR | UNKNOWN

## Regras de Uso
- Sempre iniciar em READ_ONLY até mapear o estado.
- Usar a família para classificar ações e diagnósticos.
- FIXED_POINT é o alvo; REMEDIAR ou UNKNOWN quando não atingido.
- Esta normalização é global para o repositório e deve ser seguida por qualquer corpo que opere no CentralDark.
