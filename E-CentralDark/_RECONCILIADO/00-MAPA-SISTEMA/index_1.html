1. Introduction

NexChat is a powerful, highly customizable, and ultra-modern web messenger UI built with React.js, Vite, Tailwind CSS, and SCSS. It was meticulously designed to handle light and dark mode automatically while delivering an ultra-premium "glassmorphism" aesthetic.

Whether you are building a generic chat application, an AI-powered conversational interface, or a community portal, NexChat provides the elegant UI components necessary to accelerate your development process while ensuring absolute pixel-perfect visual fidelity.

2. Key Features

  • 🟢 Dynamic Template & Customization: Instantly switch between Light/Dark mode, change Template color palettes natively, and toggle chat wallpapers.
  • 🟢 Integrated AI Assistant: Specialized "Ask AI" components with distinct glowing UI chat bubbles and intelligent capabilities integration.
  • 🟢 Voice & Video Calling: High-end UI screens for incoming, outgoing, and active voice and video calls featuring sonic-pulse animations.
  • 🟢 Status Updates (Stories): Mobile-inspired "Stories" style status viewer for sharing ephemeral images and videos with contacts.
  • 🟢 Groups & Channels: Organized list views and dynamic chat layouts tailored for multi-participant groups and broadcast channels.
  • 🟢 Advanced Messaging Tools: Fully designed context menus mapped to Message Edit, Delete, Quick Reply, and Forwarding UI workflows.
  • 🟢 User Online Status: Dedicated presence indicators showing real-time active, busy, invisible, or offline states across the app.
  • 🟢 Poll System: Interactive polling UI designs nested directly inside message bubbles for community voting and group tracking.
  • 🟢 Premium Glassmorphism Aesthetic: Carefully calibrated translucent panes with backdrop blurring mapped safely to CSS mixins.
  • 🟢 Fluid & Responsive: Completely flexbox/grid-based layout prioritizing modern viewport fluidity (Desktop, Tablet, Mobile).
  • 🟢 Vite Build Tool: Blazing-fast hot module replacement (HMR) and optimized build times compared to Create React App.
  • 🟢 Tailwind CSS + SCSS: Combines the rapid prototyping of Tailwind's utility classes with the structured architecture of professional SCSS.
  • 🟢 Zustand State Management: Ultra-lightweight and predictable state management system built-in for handling user settings and states.

4. Getting Started

Follow these simple steps to get your project up and running in your local development environment.

Prerequisites

Ensure you have Node.js installed (v16.0 or higher is recommended).

Installation Steps

  1. Extract the Archive
    Unzip the downloaded package to your preferred directory.
  2. Install Dependencies
    Open your terminal/command prompt, navigate to the extracted root directory, and run the following command: 
    npm install
  3. Start the Development Server
    Once dependencies are installed, start the local Vite server: 
    npm run dev

    This will start your app on `http://localhost:3000` (or the next available port).

  4. Build for Production
    When you are ready to deploy your app, run: 
    npm run build

    This command will compile and bundle your app into the /dist folder, optimizing your SCSS and Javascript for the highest performance.

The template features a perfectly organized, modular directory structure:

├── documentation/       # This help documentation folder
├── node_modules/        # Installed NPM packages (generated)
├── public/              # Static files (images, icons, manifest)
├── src/                 # Main Source Code
│   ├── assets/          
│   │   └── scss/        # Core SCSS architecture (Layouts, Components, Variables)

│   ├── pages/           # High-level route views (Landing, Messenger, Auth)
│   ├── store/           # Zustand state files (themeStore.ts)
│   ├── App.tsx          # Main React Application router/wrapper
│   ├── index.css        # Tailwind directives and CSS Custom Properties
│   └── index.tsx        # React DOM entry point
├── .gitignore
├── index.html           # Main HTML shell
├── package.json         # Project configuration and script commands
├── tailwind.config.js   # Tailwind framework configurations
├── tsconfig.json        # TypeScript configurations
└── vite.config.ts       # Vite bundler configurations

6. Customization

Modifying Template Colors

NexChat uses a powerful combination of CSS Variables and Tailwind configuration to instantly switch colors globally without breaking the SASS builds.

To change the primary structural colors of Light and Dark Template, open src/index.css and update the root RGB values:

:root {
    --color-primary: #13ec5b; /* Main Brand Accent Color */

    /* Light Mode Variables */
    --color-background-dark: 246 248 246; 
    --color-surface-dark: 255 255 255; 
}

html.dark {
    /* Dark Mode Variables */
    --color-background-dark: 16 34 22; 
    --color-surface-dark: 22 43 30; 
}

SCSS Architecture

If you prefer writing highly specific custom classes, navigate to src/assets/scss/. The styles are split modularly:

  • _variables.scss: Contains SASS color mappings that listen to Tailwind variables automatically.
  • _mixins.scss: Contains helpers like the `scrollbar` generator and `glass` blur logic.
  • layout/: Contains the backbone grids and containers like _sidebar.scss and _chat.scss
  • components/: Granular control over the UI elements like _buttons.scss.

Adding/Removing Dependencies

Since this project uses NPM, you can simply run npm install [package-name] to add a new library, or remove unused components safely.
