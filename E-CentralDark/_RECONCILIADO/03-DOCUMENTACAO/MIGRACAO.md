# Migração para o módulo multizap

## Objetivo

Organizar o produto atual dentro da estrutura CentralDark.

Destino final:

```txt
/root/CentralDark/apps/modulos/multizap/
```

## Ordem correta

1. Organizar repositório.
2. Atualizar documentação.
3. Ajustar instalador.
4. Validar deploy.
5. Sincronizar VPS.
6. Migrar legado.
7. Limpar estrutura antiga apenas após validação.

## Regra principal

A VPS não é a fonte da verdade.

A fonte da verdade é o repositório organizado.
