# Pasta antiga - Notificacoes

Esta pasta fica como referencia antiga.

A pasta oficial agora e:

```txt
apps/central-notificacoes/
```

## Explicacao leiga

Antes o modulo aparecia como `apps/notificacoes/`.

Agora o nome ficou mais claro: Central de Notificacoes.

Use `apps/central-notificacoes/` para novas documentacoes, codigo e integracoes.

## Relacao com a Central de Logs

```txt
apps/central-logs registra o erro
  -> se precisar avisar alguem
  -> apps/central-notificacoes envia o aviso
```
