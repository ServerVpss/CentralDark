# apps/modulos/

Módulos de negócio da CentralDark. Cada módulo é um produto ou funcionalidade que pode ser ativado dentro do portal.

## O que tem aqui

- `multizap/` — WhatsApp multi-instância (gateway + bot + integrações)
- `financeiro/` — cobrança, assinaturas, recargas
- `telepainel/` — painel de controle via Telegram

Veja o `PLANO.md` de cada módulo para detalhes.
