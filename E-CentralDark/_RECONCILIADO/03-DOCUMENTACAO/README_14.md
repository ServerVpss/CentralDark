# secrets.example

**Template** de como a pasta `secrets/` deve ficar na VPS.

- Pasta real: `/root/CentralDark/secrets/` — **nunca versionada**, permissão 700.
- Arquivos esperados (exemplo):
  - `mcp.env`
  - `cloudflare.env`
  - `supabase.env`
  - `telegram.env`

Aqui só ficam exemplos com chaves vazias, nunca valores reais.
