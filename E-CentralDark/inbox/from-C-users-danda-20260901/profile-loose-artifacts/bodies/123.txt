## Objetivo

Planejar e implementar uma base privada no Telegram para acompanhar a CentralDark em tempo real, usando um grupo principal com tópicos.

Telegram será janela viva de observabilidade, não fonte da verdade.

## Base técnica confirmada

A Telegram Bot API permite:

- criar tópicos com `createForumTopic`;
- enviar mensagens para tópico específico usando `message_thread_id`;
- gerenciar tópicos quando o bot é admin com permissão `can_manage_topics`.

Fonte: https://core.telegram.org/bots/api

## Travas

- Não enviar secrets, tokens, `.env`, payload sensível ou logs crus.
- Telegram não substitui GitHub/docs/Supabase como memória oficial.
- Bot precisa operar com allowlist de tópicos e templates.
- Ações sensíveis continuam exigindo Manual Confirm.
