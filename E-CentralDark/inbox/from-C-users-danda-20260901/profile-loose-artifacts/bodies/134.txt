## Investigação read-only sugerida

Sem alterar DNS/Caddy/Nginx/PM2:

```bash
find /root/CentralDark -type f \( -name '*.md' -o -name '*.js' -o -name '*.mjs' -o -name '*.ts' -o -name '*.tsx' -o -name '*.json' -o -name '*.yml' -o -name '*.yaml' -o -name '*.conf' \) -print0 | xargs -0 grep -InE '[a-z0-9.-]+\.centralldark\.com' || true
pm2 list
```

Se existir Caddy/Nginx local, listar somente arquivos de config e domínios, sem secrets.
