## Itens apontados

### #54 — GitHub token exposto

Ação humana necessária:

- revogar tokens antigos/desconhecidos;
- gerar novo token com escopo mínimo necessário;
- armazenar em cofre/secret store;
- nunca enviar token por chat.

Variável recomendada para padronização:

```text
CENTRALDARK_GITHUB_PAT
```

Aliases runtime, se scripts legados exigirem:

```text
GH_TOKEN -> CENTRALDARK_GITHUB_PAT
GITHUB_TOKEN -> CENTRALDARK_GITHUB_PAT
```

Observação: em GitHub Actions, preferir o `GITHUB_TOKEN` nativo quando for suficiente. Usar PAT apenas quando workflow precisar de escopo extra, como `workflow`.
