## Como resolver

Opção A — GitHub UI:

1. Abrir `Settings` do repositório.
2. Entrar em `Labels`.
3. Editar cada label acima.
4. Aplicar as cores sugeridas.

Opção B — Automação futura:

Criar script ou GitHub App com permissão de labels para atualizar descrição/cor via API.
