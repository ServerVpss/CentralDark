


---

### 4. Commits automáticos e loops

Investigar qualquer automação que:

```txt
commita sozinha
git commit
git push direto na main
atualiza timestamp
atualiza painel-data.json
corrige memória automaticamente
```

Achado já confirmado:

```txt
Commits repetidos chore(painel): IA atualiza painel — atualização
Arquivo: apps/modulos/status/painel-data.json
Mudança: updatedAt / updatedAtBR
```

Decisão esperada:

```txt
Estado vivo não deve commitar na main.
Estado vivo deve ir para Supabase / Edge Function / painel-write.
```

---
