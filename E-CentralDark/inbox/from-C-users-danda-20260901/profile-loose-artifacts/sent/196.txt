## Ordem do Pivete

O CentralDark não pode ficar apenas monitorando e comentando "ainda na fila". Cada alerta precisa terminar em uma destas saídas:

```text
RESOLVIDO com PR + prova
BLOQUEADO com motivo + responsável humano
ENCERRADO porque o serviço já voltou e a issue ficou obsoleta
```

## Plano obrigatório por fases

### FASE 1 — restaurar o sistema que chama os agentes

Responsável inicial: `assign:codex`

1. Diagnosticar #21 primeiro.
2. Corrigir Bot Controller em branch própria.
3. Provar com uma issue-teste inofensiva que um label gera execução real e comentário do agente.
4. Depois validar #16, #68 e #117.

**Sem esta fase, não abrir mais missões automáticas.**

### FASE 2 — corrigir incidente real

1. Executar #195 e #23.
2. Corrigir o HTTP 502 do Install.
3. Confirmar 200 interno e externo.
4. Fechar #23 após duas verificações verdes consecutivas.

### FASE 3 — parar spam e usar mudança de estado

```text
estado igual → não commitar, não comentar, não disparar webhook
UP → DOWN → abrir/atualizar incidente + webhook
DOWN → UP → registrar recuperação + webhook
```

Guardar telemetria em Supabase, artifact, cache ou storage — não em commits repetidos na `main`.

### FASE 4 — limpar fila de PRs

Para cada PR aberto, responder:

```text
MANTER E AUDITAR
ATUALIZAR/REBASEAR
SUBSTITUÍDO POR OUTRO PR
FECHAR COMO OBSOLETO
BLOQUEADO POR SEGURANÇA
```

Nenhum PR deve ficar indefinidamente aberto sem decisão.

### FASE 5 — regra permanente de autonomia

Cada agente precisa registrar:

```text
Missão recebida:
Início real:
Branch:
SHA:
Ação executada:
Teste:
PR:
Bloqueio, se houver:
Próximo responsável:
Status: TRABALHANDO | RESOLVIDO | BLOQUEADO
```

Check-in sem mudança de estado é proibido.
