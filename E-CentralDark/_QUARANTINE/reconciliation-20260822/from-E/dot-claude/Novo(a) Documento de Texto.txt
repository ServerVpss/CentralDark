## O que deve virar código bruto

Tudo que já possui resposta objetiva vira **script determinístico**, não nova análise de IA:

```text
PM2 online, mas endpoint falha
→ detectar automaticamente

configuração do PM2 diferente do arquivo
→ comparar por hash, sem mostrar segredo

cron termina com código 0
→ classificar como execução saudável, não queda

arquivo de pedido novo + resposta velha
→ declarar consumidor ausente ou atrasado

rota devolve texto 503
→ rota morta

rota devolve JSON 401 com chave falsa
→ protocolo vivo, autenticação funcionando como gate

processo mudou PID/restart/status
→ registrar transição real

correção aplicada
→ repetir as mesmas provas automaticamente
```

A IA não precisa gastar tokens redescobrindo isso. **Ela entra somente quando o detector encontrar algo que nenhuma regra conhecida consegue classificar.**

## A autonomia correta

Não é “deixar uma IA solta corrigindo tudo”.

É:

```text
DEFEITO CONHECIDO
→ script detecta
→ aplica correção segura previamente autorizada
→ contraprova
→ receipt

DEFEITO DESCONHECIDO
→ IA da VPS recebe snapshot sanitizado
→ investiga em read-only
→ propõe causa e correção
→ Delta entra somente se o território for amplo

AÇÃO DESTRUTIVA OU FORA DO ESCOPO
→ trava no Chefe
```

Isso se chama **autonomia por evidência**, não autonomia por confiança em modelo.
