# Voz local

## Runtime

- `Kokoro-FastAPI`: TTS local OpenAI-compatible.
- Ambiente Python: `.venv` dentro do projeto.
- Porta planejada: `127.0.0.1:8880`.
- Provas de audio: `provas/`.

## Limites

- Este pacote e uma capacidade local de voz, nao um novo sistema CentralDark.
- O roteamento canonico continua sendo responsabilidade da API/owners da
  CentralDark.
- Nenhum segredo real e armazenado nesta pasta.
