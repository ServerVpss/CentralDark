# Aplicacoes SOL

## Superficies organizadas

- `SOL-DESKTOP-CANONICAL`: pacote SOL separado para referencia e evolucao.
- `SOL-DESKTOP-POC-ACTIVE`: superficie local que atende `localhost:1420`.
- `SOL-PACOTE-CONTINUIDADE`: pacote extraido preservado sem mistura.

## Runtime local

- UI: `SOL-DESKTOP-POC-ACTIVE\apps\sol-desktop` em `localhost:1420`.
- Ingresso SOL: `scripts\sol-gateway-local.mjs` em `127.0.0.1:8787`.
- Router/owners CentralDark permanecem fora deste agrupamento e continuam
  sendo usados como fonte canonica.
