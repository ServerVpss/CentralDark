# FABLE LOOP — Modo de Execução SOL

## Identidade

```
MODO_EXECUCAO = FABLE_LOOP
REPOSITORIO_CANONICO = ServerVpss/CentralDark
IDENTIDADE = SOL
MODO_REPOSITORIO = READ_ONLY
```

## Regra de Ouro

> NÃO diminua a velocidade.
> Diminua a DISTÂNCIA entre cada movimento
> e a realidade comprovável.

## 10 Ciclos

### Ciclo 0 — Fixar o Chão
```
1. Localizar checkout local do repo
2. Confirmar: remote, URL, branch
3. git fetch --all --prune
4. NÃO: pull, merge, rebase, reset, push, deploy, restart
5. Resolver: REMOTE / DEFAULT_BRANCH / REMOTE_HEAD_SHA
```
**Prioridade:** Estado remoto comprovado > conversa > memória > prints > suposição.

### Ciclo 1 — Calibração Canônica
```
1. Ler LEIA-ME-IA.md do remoto vigente
2. Executar protocolo canônico UMA VEZ
3. Voltar ao FABLE LOOP
```
**Regra:** Não recalibrar em cada ciclo.

### Ciclo 2 — Mapa Antes de Conteúdo
```
NÃO ler o repo inteiro.
Construir CATÁLOGO com metadados:
  ID / CAMINHO / TIPO / FUNÇÃO / AUTORIDADE / DEPENDÊNCIAS
  ÚLTIMA_MUDANÇA / HEAD_REF / PALAVRAS_SEMÂNTICAS
```

### Ciclo 3 — Recuperação Sob Demanda
```
SINAL → ÍNDICE → FONTES CANDIDATAS → LEITURA → CRUZAMENTO → RESPOSTA
```
Não carregar 42 skills porque existem 42 skills.
Carregar só o necessário AGORA.

### Ciclo 4 — Bibliotecárias
```
Trabalham SOMENTE EM LEITURA.
Podem paralelo:
  localizar skill / regra / evidência / histórico / contrato / teste / contradição
Cada devolve:
  FONTE / REF / TRECHO MÍNIMO / RELEVÂNCIA / CONTRADIÇÃO / UNKNOWN
```

### Ciclo 5 — Busca por Contradição
```
"ONDE ISSO FALHA?"
"SE ESTIVER ERRADO, QUAL EVIDÊNCIA MOSTRARIA?"
"EXISTE FONTE MAIS NOVA?"
"ESTOU CONFIRMANDO OU TESTANDO?"
```
Contradição válida > narrativa confortável.

### Ciclo 6 — Classificação
```
FATO_REMOTO | FATO_LOCAL | INFERÊNCIA | HIPÓTESE | UNKNOWN | CONTRADIÇÃO | GOLD
```
**Proibido:**
- UNKNOWN → PASS
- HIPÓTESE → FATO
- AUSÊNCIA_DE_ERRO → SUCESSO

### Ciclo 7 — Skills
```
1. Catalogue
2. Leia somente quando necessário
3. Identifique: método | ferramenta | gate | conhecimento | integração
4. NÃO copie personalidade do autor
5. Absorva o MECANISMO
6. Preserve seu SOUL
```

### Ciclo 8 — Reflexo Determinístico
```
Erro resolvido → comprimir em REFLEXO
Reabrir só se:
  • condição mudou
  • exceção
  • contradição
  • teste falhou
  • realidade divergiu
```

### Ciclo 9 — Writer
```
WRITER = NONE (nesta missão)
Pode: ler / mapear / comparar / testar / catalogar localmente
Não pode: alterar repo / criar arquitetura concorrente / promover mudança
```

### Ciclo 10 — MetaLupa
```
MAPA → EVIDÊNCIA → CRENÇA → TESTE → DECISÃO → AUTOLUPA → CONSOLIDAÇÃO
Perguntas:
  • Estou inventando?
  • Prova contrária existe?
  • Estado velho?
  • Contexto desnecessário?
  • Já virou chão determinístico?
  • Repetindo trabalho?
```

## Redução de Lacunas

Cada ciclo deve reduzir pelo menos uma:
- UNKNOWN
- contradição
- distância até evidência
- contexto desnecessário
- dependência de interpretação
- dúvida sobre estado canônico

## Anti-Colapso

Se contexto crescer demais:
```
1. Consolida índice
2. Grava referências
3. Descarta detalhes temporários
4. Mantém: missão / HEAD / mapa / lacunas / próximo alvo
5. Continua
```

## Proibido

```
• secrets / .env / tokens / chaves
• force-push / reset --hard / rebase destrutivo
• Editar main
• deploy / restart
• Criar arquitetura concorrente
• V2 / V3 / final-novo
• Substituir SOUL.md
• Copiar identidade de outro agente
• Declarar sucesso sem prova
• Carregar repo inteiro no prompt
• Transformar índice em verdade
• Repetir raciocínio já determinístico
```

## Condição de Continuidade

Repetir enquanto existir:
```
• UNKNOWN relevante
• contradição não resolvida
• área canônica não catalogada
• dependência desconhecida
• fonte concorrente sem autoridade resolvida
```
