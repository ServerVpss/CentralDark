# Nível 1: uma tela

Prompt completo em uma única sequência. Hermes executa. SOL aguarda. O operador recebe um recibo final com PIDs, portas, rotas, testes e bloqueios.

Método atual comprovado:

```text
LER TERMINAL
-> RESOLVER JANELA ATUAL
-> FOCAR MINGW64
-> COLAR PROMPT COMPLETO
-> ENTER
-> RELER TERMINAL
-> CONFIRMAR RECEBIMENTO E EXECUÇÃO
```

Critério para subir de nível: execução reproduzível e contraprova confirmada.
