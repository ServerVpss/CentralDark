# MISSÃO — ZERAR TODAS AS ISSUES DO CENTRALDARK

## ORDEM DO PIVETE

```text
RESOLVA TODAS AS ISSUES ABERTAS DO REPOSITÓRIO ServerVpss/CentralDark.

USE A LUPA-BAYESIANA EM VOCÊ MESMO DURANTE TODA A MISSÃO.
APLIQUE AUTOLUPA NO FINAL DE CADA ISSUE E NO FECHAMENTO GERAL.

RESOLVE. VÁ ATÉ O FIM.
PERMITO PIVETE SEM AÇÃO DESTRUTIVA. 🔒🚀
```

## OBJETIVO

Transformar cada issue aberta em um destes estados comprovados:

```text
RESOLVIDA
DUPLICADA COM DESTINO COMPROVADO
OBSOLETA COM EVIDÊNCIA
JÁ CORRIGIDA E VALIDADA
BLOQUEADA POR DECISÃO REAL DO PIVETE
```

Não deixar issue aberta por falta de organização, esquecimento, erro intermediário ou provider indisponível.

## FLUXO OBRIGATÓRIO

```text
listar todas as issues abertas
→ ler corpo, comentários, labels, PRs e commits relacionados
→ agrupar por causa raiz e dependência
→ ordenar por criticidade e desbloqueio
→ delegar frentes paralelas
→ corrigir em branches de escopo coerente
→ testar
→ AutoLupa
→ abrir ou atualizar PR
→ acompanhar checks
→ atualizar a issue com evidência
→ fechar somente quando comprovado
→ repetir até terminar
```

## REGRAS

1. Não fechar issue só para reduzir o contador.
2. Não criar issue duplicada.
3. Duplicadas devem apontar para a issue canônica.
4. Correções relacionadas podem compartilhar uma branch/PR coerente.
5. Issues independentes não devem ser misturadas num PR gigante.
6. Reutilizar código, documentos, scripts e infraestrutura existentes.
7. Não criar V2, serviço paralelo ou arquivo concorrente sem prova de necessidade.
8. Toda conclusão exige teste, diff, SHA, PR ou evidência reproduzível.
9. Falha de teste vira correção e reteste, não encerramento.
10. Bloqueio temporário não encerra a missão; usar fallback e retomar.
11. Registrar BEGIN/FINAL de uso da Lupa conforme o mecanismo canônico.
12. Aplicar `permito-pivete` quando o gate exigir autorização nominal já concedida.

## GATE DE FECHAMENTO

Uma issue só pode fechar quando:

```text

correção ou classificação comprovada

comentário final registrado
sem regressão conhecida
AutoLupa concluída
```
