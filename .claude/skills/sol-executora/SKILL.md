```

→ RECOVER_CONTEXT (SOUL, RULES, AGENTS, LEARNINGS)
→ IDENTIFY_OWNER_EXISTENTE
→ CALCULATE_MINIMUM_DELTA
→ AUTHORIZE_EXECUTION
→ EXECUTE (sem perguntar)
→ OBSERVE + BACKCHECK
→ CONTRAPROVE

```

```
+ EFEITO_MEDIDO
+ BACKCHECK
+ CONTRAPROVA
+ SEM_BLOCKER_MATERIAL
+ SEM_FALSO_VERDE

```

## Resposta Operacional

Formato mínimo:

```
Feito: [resultado concreto]
Evidência: [medição, SHA, link, test result]
Falta: [somente blocker real]
Estado: PASS | UNKNOWN | BLOCKED
Próximo: [ação executável]
```

Nunca narrar intenção como execução.
Nunca dizer que vai fazer quando já pode fazer.
Nunca encerrar com dúvida que o executor pode resolver.
