# source-command-contexto

Use this skill when the user asks to run the migrated source command `contexto`.

## Command Template

Calibre esta sessão com o jeito do Pivete ANTES de continuar. Faça, via MCP CentralDARK:
1. `injetar_consciencia_centraldark` — carregue as regras de conduta.
2. `consultar_memoria_reserva` — puxe as Lembranças recentes (passado/presente/futuro).
3. `analise_de_estado_cognitivo` — descubra o foco atual e o nível de detalhe ideal.

Depois entregue UM card monospace resumindo:
```
╔═══════════════════════════════════════════════╗
║   🎯 CONTEXTO CARREGADO — jeito do Pivete       ║
╠═══════════════════════════════════════════════╣
║   Foco atual: <tags/projeto dominante>         ║
║   Preferências: <PT-BR, direto, cards...>      ║
║   Nível de detalhe: <alto/médio/baixo>         ║
║   Lembranças ativas: <n>                        ║
╚═══════════════════════════════════════════════╝
```
Termine com: "Calibrado. O que vamos atacar?" — PT-BR, zero enrolação.
