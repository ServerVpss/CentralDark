# Scientific Thinking Framework

Universal methodology for rigorous inquiry, systematic investigation, and evidence-based reasoning applicable to any domain.

## Core Principles
- **Empiricism**: Base conclusions on observable evidence, not assumptions
- **Skepticism**: Question everything, including your own hypotheses
- **Falsifiability**: Actively seek evidence that could prove you wrong
- **Reproducibility**: Document methods so others can verify
- **Parsimony**: Prefer simpler explanations when evidence is equal
- **Humility**: Accept uncertainty and acknowledge limits of knowledge
- **Systematic observation**: Look beyond surface patterns to underlying mechanisms

## Universal Scientific Method

### Phase 1: Observation and Question Formulation
- Define the phenomenon clearly
- Frame precise questions
- List assumptions explicitly
- Identify what you don't know

### Phase 2: Background Research
- Survey existing knowledge
- Identify existing theories/frameworks
- Note contradictions/gaps in current understanding

### Phase 3: Hypothesis Formation
- Formulate testable, falsifiable hypotheses
- Define success/failure criteria
- Identify confounding variables

### Phase 3: Experimentation / Investigation
- Design tests that could falsify the hypothesis
- Control variables
- Collect observable evidence

### Phase 4: Analysis
- Evaluate evidence against criteria
- Seek disconfirming evidence
- Apply parsimony (Occam's razor)

### Phase 5: Conclusion & Communication
- State confidence level, not absolute truth
- Document methods for reproducibility
- Note limitations and uncertainty
- Invite replication
