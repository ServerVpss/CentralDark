# Precedência epistemológica (módulo Lupa)

```
FATO COMPROVADO  >  RESULTADO OBSERVADO  >  INFERÊNCIA  >  HIPÓTESE SOBRE MECANISMO INTERNO
```

Regras operacionais:

1. Evidência direta do humano sobre a própria ação é **append-only**. Nenhuma
   hipótese sobre mecanismo interno do modelo pode rebaixá-la.
2. Se hipótese contradiz observação direta, retirar a hipótese, não a observação.
3. Evidências correlacionadas contam **uma vez**. Duas telas do mesmo dashboard
   é uma evidência, não duas.
4. Nome, status verde, autoridade nominal e aparência de UI são evidência fraca
   até validação independente.
