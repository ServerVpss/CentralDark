# MICRO-HANDOFF — loop global contínuo até fixed point

Data: 2026-09-20
PR-mãe: #1562

Regra global canônica incorporada ao contrato existente:

```text
MAIN MOVEU
→ REMEDE HEAD
→ ABSORVE DELTA ÚTIL
→ VPS ACOMPANHA POR FF QUANDO SEGURO
→ MEDE RUNTIME
→ GRILL-ME
→ CONTRAPROVA
→ SE A FONTE DA VERDADE AVANÇAR, REPETE
→ SÓ PARA QUANDO REALIDADE = FIXED_POINT
```

Sem interrupção de conversa só para anunciar mudança de HEAD. Movimento da fonte da verdade é gatilho interno do loop, não motivo para parar a missão.
