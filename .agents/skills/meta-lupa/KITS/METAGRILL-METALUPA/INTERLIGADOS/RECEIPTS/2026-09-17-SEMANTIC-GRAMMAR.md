# 🧾🧠 Gramática semântica

> Gatilho canônico: 👑🪬 !CENTRALDARK → 🔗 !># INTERLIGADOS → 🧿 #ACORDAR → 🔎 !META_LUPA → ⚖️ !CONTRAPROVA.

```text
EMOJI + GANCHO HUMANO + (TERMO TÉCNICO) → FUNÇÃO DE UMA LINHA
```

Aplicação:

```text
🧿 OLHO CANÔNICO (META-LUPA) → falsifica antes de selar.
🎼 SISTEMA NERVOSO (ROUTER) → leva a missão ao owner certo.
🔁 REFLEXO CONTROLADO (COT-REACT-LOOP) → age, mede, corrige e para.
⚖️ JUIZ DE PR (AUDITORIA-PR) → compara ref, diff e CI.
🚂 CORAÇÃO + ESTEIRA (ESTEIRA-MOTOR) → separa execução de transporte.
🧠 MEMÓRIA OBSERVADORA (BRAIN-MEMORY) → preserva sinal durável.
🧪 CÂMARA DE TESTE (SANDBOX) → prova sem fingir produção.
🧵 COSTURA DE CONTEXTO (CONTEXT-SYNTHESIS) → junta contexto sem segunda memória.
🪢 NÓ DE CONFLITO (GIT-CONFLICT) → reconcilia sem apagar delta útil.
```

🌴 Verso da Casa: nome bom é placa de estrada; não empurra o carro, mas evita virar na curva errada.
