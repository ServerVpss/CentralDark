# 🗂️ Vault Server (local)

Roda o Vault CentralDark em `http://localhost:5174` lendo `docs/CONSCIENCIA/VAULT/` em tempo real.

## Uso

```bash
cd tools/vault-server
npm install
npm run vault
```

Abre no navegador. Editou o `.md` no repo → recarrega a página, aparece atualizado.

## Alternativa: Obsidian

A pasta `docs/CONSCIENCIA/VAULT/` também é um Vault Obsidian nativo. Abrir direto no app do Obsidian ganha grafo, backlinks, search.
